# 【1.0】前端基础之引入

# 【一】什么是前端/后端

- 任何与用户直接打交道的操作界面都可以称之为前端
  - 比如电脑界面、手机界面、平板界面

- 后端就是雷速与幕后操作者
  - 不跟用户直接打交道

# 【二】为什么学前端

- 看懂前端代码，能搭建简单的页面
