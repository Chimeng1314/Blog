请按模块、功能和变更类型，将当前改动拆分为一组小而独立的 Git 提交。

提交前请先确认每个提交的文件范围与差异；不要将无关改动、生成文件或其他模块的变更混入同一次提交。优先按下列顺序拆分：

1. 文件移动或目录结构调整
2. 内容与文档更新
3. 功能或配置变更
4. 格式化、生成文件与其他独立维护项

每次提交都应：

- 只暂存本次提交涉及的文件。
- 使用中文、简洁明确的 Conventional Commit 标题，并选择恰当的 emoji。
- 在提交正文以要点说明实际改动。
- 保留其他未完成或无关改动，不要擅自提交、还原或删除。
- 提交完成后检查工作区状态，并继续处理下一批可独立提交的改动。
