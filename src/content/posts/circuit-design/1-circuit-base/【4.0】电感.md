# 【一】什么是电感

电感器（常简称“电感”）通常由导线绕成线圈，有的带铁氧体、铁粉等磁芯。电流流过线圈会产生磁场，变化的磁场又会在线圈两端产生感应电压。

![电感器与线圈示意](https://oss.silentdream.top/2026/10/01/10-34-54-5b2b945b-image-20260930214956626-92b36c.png)

> **读图提示**：外观各异的器件都可能是电感。线圈匝数、磁芯材料、气隙、绕法和尺寸都会影响电感量、可承受电流和损耗，不能仅凭“匝数更多”判断优劣。

电感的单位是亨利（H），常用子单位：

| 单位 | 换算 | 常见量级 |
| --- | --- | --- |
| mH（毫亨） | `10⁻³ H` | 音频滤波、继电器线圈等 |
| µH（微亨） | `10⁻⁶ H` | 开关电源、电源滤波 |
| nH（纳亨） | `10⁻⁹ H` | 高频/RF 匹配、寄生电感 |

# 【二】核心规律：电感反对电流变化

电感两端的电压与流过它的电流变化率成正比：

$$
v_L=L\frac{\mathrm d i_L}{\mathrm d t}
$$

- 电流想变化得越快，电感两端需要的电压越高；
- 电感量 `L` 越大，在相同电压下电流变化得越慢；
- 当电感电流恒定时，理想电感两端电压为 0 V。

```text
电压加到电感上：       电感电流的斜率：

     +VL                         di/dt = VL / L
  ────[ L ]────                  正电压 → 电流上升
     -                            负电压 → 电流下降
```

> 口语中常说“电感阻碍电流”，更准确的是：**电感阻碍电流的突然改变**。理想电感在直流稳态下接近短路，但真实器件仍有绕线电阻。

## 【1】储能关系

电感以磁场形式储能：

$$
E_L=\frac12 LI^2
$$

断开含电感的回路时，电感电流不能瞬间归零。为了维持原电流方向，电感会产生反向的高电压，这就是继电器线圈断电时容易打火、MOSFET 容易被尖峰击穿的原因。

```text
线圈断电时的续流二极管（低速 DC 线圈常用）

 VCC ──[ 线圈 L ]──●── 开关/MOSFET ── GND
        │           │
        └──|<|──────┘
           续流二极管：正常时反偏，断电时给线圈电流提供回路
```

二极管会降低关断尖峰，但也会让线圈释放能量更慢；快速释放的驱动电路可能改用 TVS、齐纳钳位或专用驱动器，需按器件耐压和 EMI 要求设计。

# 【三】直流与交流中的表现

## 【1】直流稳态

理想电感在直流稳态下相当于短路。真实电感还存在直流电阻（DCR），因而会产生压降和铜耗：

$$
V_\mathrm{DCR}=I\times\mathrm{DCR},\qquad P_\mathrm{copper}=I^2\times\mathrm{DCR}
$$

## 【2】交流/变化信号

正弦稳态下，理想电感的感抗为：

$$
X_L=2\pi fL
$$

频率越高或电感量越大，感抗越大。因此在合适的频段内，串联电感可抑制高频电流、让较低频/直流成分通过。真实器件受寄生电容影响，在自谐振频率（SRF）附近和以上不再表现为理想电感，必须查阻抗-频率曲线。

```text
串联电感的滤波直觉：

电源/信号 ──[ L ]──●── 负载
                    │
                   [ C ]
                    │
                   GND

高频噪声：L 增加串联阻抗，C 为噪声提供到地的低阻抗路径
```

> **构图说明**：这是典型 LC 低通滤波框架。电感和电容的“通/阻”不是绝对的，效果取决于频率、源阻抗、负载和寄生参数。

# 【四】开关电源中的电感：把脉冲变成连续输出

以降压型（Buck）电源为例，开关节点快速接通/断开，电感把开关产生的脉冲能量平滑地交给负载和输出电容：

```text
Vin ── 开关 ──●── [ L ] ──●── Vout
              │            │
            二极管/同步管  [ Cout ]
              │            │
             GND          GND
```

- **开关导通**：电感两端获得正电压，电感电流上升，储存能量；
- **开关关断**：电感维持原电流方向，经二极管或同步 MOSFET 向负载继续供能，电流下降；
- **输出电容**：吸收电感电流的纹波，减小输出电压波动。

电感不是简单“滤掉高频”的附件，而是 Buck、Boost、Flyback 等拓扑完成能量转移的核心器件。选值要结合控制器手册、开关频率、输入输出范围、目标纹波和瞬态响应计算。

# 【五】关键参数与选型

| 参数 | 含义 | 常见风险 |
| --- | --- | --- |
| 电感量 L | 电流变化的“惯性”大小 | 过小纹波大，过大可能体积大、响应慢或成本高 |
| DCR | 绕线直流电阻 | 造成压降、发热和效率下降 |
| 饱和电流 `I_sat` | 磁芯开始明显饱和的电流 | 饱和后 L 骤降，电流可能失控上升 |
| 温升/额定电流 `I_rms` | 由铜损和热决定的连续电流能力 | 不等同于饱和电流，两者都要满足 |
| SRF | 自谐振频率 | 高频滤波失效甚至呈电容性 |
| 屏蔽结构 | 磁通是否更集中 | 非屏蔽电感更易对周边敏感电路产生磁干扰 |

选型时通常需要：`I_sat` 高于峰值电感电流并留温度与容差余量；`I_rms` 覆盖 RMS 电流；DCR 尽量低但兼顾尺寸与成本。不要把数据手册中不同厂家的“额定电流”直接横向比较，先确认其定义。

# 【六】PCB 布局与测量要点

## 【1】布局

- 开关电源的 `开关管—二极管/同步管—输入电容` 高 di/dt 回路要**最小、最短、最宽**；
- 电感靠近开关芯片和输出电容，开关节点铜皮面积要小，远离反馈线、晶振、射频和高阻模拟输入；
- 大电流电感下方避免走敏感信号；磁场敏感器件（磁力计等）要留足距离；
- 参考官方 Layout 示例，尤其是 Buck/Boost 芯片的输入电容位置。

## 【2】测量

用万用表可测 DCR，但很难准确测很小的 µH 电感量；LCR 表可在指定频率和测试电平下测量。用示波器探测开关节点时，长地线会引入巨大测量环路和假振铃，应使用短弹簧地或差分探头。

# 【七】常见误区与自检

- “电感完全阻直流”是错的；理想电感阻碍的是**变化**，直流稳态下反而近似短路。
- “电感永远阻高频”过于绝对；SRF 以上寄生电容会主导行为。
- 只看标称 µH、不看饱和电流和 DCR，是开关电源常见失效原因。
- 线圈断电尖峰是真实能量释放，不能用“断开了就没有电流”来忽略。

**快速自检**：10 µH 电感两端加 5 V 理想恒压，其电流上升斜率为 `5 / 10 µH = 0.5 A/µs`。
