# 【一】USB 转串口芯片的作用

USB 转串口芯片让计算机的 USB 接口与设备的 UART 通信。主机侧枚举为虚拟串口（CDC/厂商驱动），设备侧输出通常是 MCU 可用的逻辑电平 UART：`TXD`、`RXD`，有时还包含 `RTS`、`CTS`、`DTR`、`DSR` 等控制线。

![USB 转串口芯片与接口示意](https://oss.silentdream.top/2026/10/02/01-12-28-b3e1d96e-image-20261001225436023-f3272c.png)

```text
PC USB ── D+ / D− ── [ USB-UART 芯片 ] ── TXD/RXD ── MCU UART
                         │       │
                       VBUS     GND
```

> **关键区分**：USB、TTL/CMOS UART、RS-232、RS-485 不是同一种电气接口。USB 转串口芯片的 TXD/RXD 多为 3.3 V 或 5 V 逻辑 UART；要接 RS-232 或 RS-485 总线，还需要对应电平/收发器芯片。

# 【二】接口与通信基础

## 【1】USB 侧

USB 2.0 全速设备使用一对差分数据线 D+、D−，通过枚举与主机通信。PCB 上应按芯片手册处理差分阻抗、ESD、串联电阻（若需要）、VBUS 检测和去耦。

```text
USB 连接器
VBUS ── 保险/电源开关 ── 设备 5 V（按设计需要）
D+   ── ESD ── 串阻（可选）── 芯片 D+
D−   ── ESD ── 串阻（可选）── 芯片 D−
GND  ────────────────────────── 系统地/屏蔽策略
```

ESD 器件应放在连接器附近，D+/D− 到保护器件与地的路径应短且低电感。高速 USB 上要选低结电容 TVS 阵列，普通大功率 TVS 可能严重劣化信号完整性。

## 【2】UART 侧

UART 是异步串行通信，至少由发送 `TX`、接收 `RX` 和共地组成。连接原则是交叉：

```text
USB-UART TXD ──→ MCU RX
USB-UART RXD ──← MCU TX
GND            ─── MCU GND
```

常用帧格式为 8N1（1 个起始位、8 个数据位、无校验、1 个停止位），但波特率、校验、停止位必须两端一致。UART 是点对点、短距离、地参考接口；长距离/强干扰工业现场优先考虑 RS-485 或隔离收发器。

## 【3】电平兼容

| 接口 | 典型电平/方式 | 不能直接混接的原因 |
| --- | --- | --- |
| USB | 差分 D+/D− | 协议、电平与物理层完全不同 |
| TTL/CMOS UART | 单端 3.3 V 或 5 V 逻辑 | 需共地，输入不能超压 |
| RS-232 | 正负电压、反相逻辑 | 需 MAX3232 等收发器 |
| RS-485 | 差分 A/B，总线拓扑 | 需 RS-485 收发器、端接/偏置 |

“5 V USB”是 VBUS 供电电压，不等于串口 TXD 一定为 5 V。使用 USB-UART 模块前先确认 IO 电平选择脚、板载稳压器以及 MCU 是否 5 V 容忍。

# 【三】常见芯片与模块

## 【1】常见芯片对比

| 系列 | 常见特点 | 选用时需确认 |
| --- | --- | --- |
| FTDI FT232 系列 | 功能丰富、生态成熟、部分型号支持更多 GPIO/协议 | 型号、驱动、供电与封装 |
| Prolific PL2303 系列 | 常见于各类模块 | 具体版本与系统驱动兼容性 |
| Silicon Labs CP210x 系列 | 集成度高、常用于开发板 | 型号的 USB 枚举、IO 电平与驱动 |
| WCH CH340 系列 | 成本低、模块广泛 | 不同后缀型号的晶体/供电/IO 要求 |

不能只按芯片家族判断性能。不同型号对外部晶体、EEPROM、VBUS 检测、供电电压、最大波特率、流控和 GPIO 功能的要求差异很大，原理图应直接以所选型号的参考设计为准。

# 【四】下载、复位与自动进入 Bootloader

许多开发板利用 DTR/RTS 的状态变化，经电容耦合或晶体管电路控制 MCU 的 `RESET`、`BOOT`/`IO0` 等引脚，实现自动下载：

```text
USB-UART DTR/RTS ── 自动复位电路 ── MCU RESET / BOOT 引脚
USB-UART TXD/RXD ───────────────── MCU UART
```

不同 MCU 的启动脚和有效电平不同，不能照搬其他板子的自动下载电路。设计前需读 MCU Boot ROM 文档和官方开发板原理图；复位/启动脚还需有合适上拉/下拉，避免上电随机进入下载模式。

# 【五】布局、调试与常见问题

## 【1】布局要点

- USB 连接器、ESD、USB-UART 芯片尽量靠近，D+/D− 成对、等长趋势、少过孔、远离开关节点；
- 连接器屏蔽壳如何接机壳地/数字地，应按整机 EMC 与参考设计确定；
- VBUS、芯片 VDD 与每个去耦电容组成最小回路；
- UART 若引到排针或外部线缆，预留 ESD、串联电阻和电平转换位置。

## 【2】排错顺序

1. 插 USB 后先检查操作系统是否枚举出设备；
2. 若未枚举，测 VBUS、芯片供电、D+/D− 短路/焊接、晶体和 ESD 器件方向；
3. 若能枚举但无串口数据，确认 TX/RX 是否交叉、是否共地、波特率/帧格式是否一致；
4. 若只能单向通信，检查另一方向的 IO 电平、MCU 引脚复用、串联电阻和外部占用；
5. 若下载失败，观察 RESET/BOOT 波形与手动下载是否可用，再检查自动下载电路。
