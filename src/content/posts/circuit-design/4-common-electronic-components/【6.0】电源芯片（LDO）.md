# 【一】LDO：低压差线性稳压器

LDO（Low Dropout Regulator）是能在较小输入—输出压差下维持稳定输出的线性稳压器。它通过内部调整管把多余压差转换为热，因此外围简单、噪声通常较低，但效率受输入输出电压比限制。

> 线性稳压器不都属于 LDO。经典 78xx 系列通常需要约 2 V 或更高压差，属于传统线性稳压器；具体是否“低压差”必须看所选型号在目标输出电流下的 dropout 曲线。

# 【二】工作原理与基本结构

![LDO 内部控制环路示意](https://oss.silentdream.top/2026/10/02/01-12-28-769d4937-image-20261001230529964-6f4a22.png)

```text
Vin ──→ [ 调整管 ] ──→ Vout ──→ 负载
             ↑              │
             └── 误差放大器 ← 基准与反馈分压
```

控制环路比较反馈电压与内部基准，自动改变调整管导通程度。输入电压足够高且未触发限流/过温时，输出保持设定值；若 `Vin` 接近 `Vout`，调整管已完全导通仍无法补偿，输出会随输入下降，这就是 dropout 状态。

# 【三】效率、发热与压差

## 【1】效率与损耗

忽略静态电流时，LDO 的理想效率近似为：

$$
\eta\approx\frac{V_{OUT}}{V_{IN}}
$$

芯片自身主要耗散功率为：

$$
P_{LOSS}\approx\left(V_{IN}-V_{OUT}\right)I_{OUT}+V_{IN}I_Q
$$

其中 `I_Q` 为静态电流。例：12 V 降到 3.3 V、负载 100 mA，仅压差损耗就约 0.87 W；即使电流不大，小封装也会很热。大压差/大电流时通常应使用 Buck 等开关电源先降压，再用 LDO 做低噪声后级。

## 【2】压差与最低输入电压

```text
要得到稳定 Vout：
Vin(min) ≥ Vout + Vdropout（目标电流、温度条件下）
```

`Vdropout` 与输出电流、温度和器件结构有关，不能只取宣传页上的“典型 100 mV”。电池放电或整流纹波的最低谷值也必须满足上式。

# 【四】关键参数与选型

## 【1】参数表

| 参数 | 意义 | 选型要点 |
| --- | --- | --- |
| 输入电压范围 | 可正常工作的 Vin 区间 | 包括启动、浪涌和绝对最大额定值 |
| 输出电压/精度 | 固定或可调输出及初始误差 | 与系统容差、校准要求匹配 |
| dropout | 稳压所需最小压差 | 必须看目标电流下的最大值 |
| 最大输出电流 | 限流条件下的能力 | 连续电流还受热设计限制 |
| 静态电流 `I_Q` | 芯片自身消耗 | 电池待机应用关键 |
| PSRR | 对输入纹波的抑制 | 看目标噪声频段，不是单一数值 |
| 输出噪声 | 自身噪声密度/积分噪声 | ADC、RF、音频供电重要 |
| 输出电容稳定性 | 容量与 ESR 要求 | 不满足可能振荡 |
| 保护功能 | 限流、短路、过温、反向等 | 保护不应代替正常设计余量 |

## 【2】78xx 与 AMS1117 的正确定位

- **78xx/7805**：经典固定正输出线性稳压器，压差相对较大，封装与厂家版本很多；适合输入电压富余、功耗可控的简单电源。
- **AMS1117 类**：常见可调/固定线性稳压器，压差比 78xx 低，但静态电流、热性能和输出电容要求未必适合低功耗设计；市场上有大量兼容/仿制版本，参数必须以具体数据手册为准。

不要从“标称最大 1 A”推断可在任意电压差下持续输出 1 A。热限制往往先于电流限制到来。

# 【五】典型应用与布局

## 【1】基本连接

```text
Vin ── Cin ── [ LDO ] ── Cout ── Vout → 负载
 │             │          │
GND ───────────┴──────────┴────────── GND

Cin/Cout 紧贴对应引脚，容量与 ESR 按数据手册选择
```

输入电容降低供电阻抗，输出电容参与控制环路稳定和负载瞬态响应。某些 LDO 对最小容量、最大 ESR 或陶瓷电容有明确限制；“随便并一个 0.1 µF”不一定可靠。

## 【2】热设计

```text
芯片结温 Tj = 环境温度 Ta + 损耗功率 × 热阻 θJA（粗略估算）
```

热阻受封装、铜皮面积、热过孔、层数和气流影响。先根据功耗估算温升，再参考手册的降额曲线和推荐 PCB 铜皮；发现输出掉压时不要只怀疑输入电压，也要检查是否触发热保护。

# 【六】常见问题与测试

| 现象 | 常见原因 | 处理方向 |
| --- | --- | --- |
| 输出低于标称值 | 输入压差不足、过温/限流、负载过大 | 测 Vin 最低谷、芯片温度和负载电流 |
| 输出振荡/噪声大 | Cout 不满足稳定性要求、布局回路大 | 对照手册容量/ESR，短接地回路 |
| 待机电流过高 | 选了高 `I_Q` 器件、外部泄漏 | 测无负载电流，换低静态电流 LDO |
| 输出被反向灌电 | 输出端外部电源高于输入 | 查反向电流规格，按手册加保护 |
| 芯片很烫 | 压差和电流造成过大损耗 | 换 Buck、降负载或加强散热 |
