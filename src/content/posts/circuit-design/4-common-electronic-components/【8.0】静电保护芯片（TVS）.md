# 【一】TVS：瞬态过压的第一道防线

TVS（Transient Voltage Suppressor，瞬态电压抑制器）是专门用于钳制 ESD、浪涌、感性尖峰等瞬态过压的半导体器件。正常工作时它呈高阻；电压超过一定范围时迅速导通，把浪涌电流分流并限制后级看到的电压。

![单向与双向 TVS 的符号/伏安特性示意](https://oss.silentdream.top/2026/10/02/01-12-28-33fc9072-image-20261001232316925-8fac08.png)

> TVS 不是“万能保险”。实际钳位电压由 TVS 本体、浪涌电流、PCB/线缆寄生电感和回流路径共同决定。器件离连接器很远或接地回路很长，即使选了低钳位型号，芯片端仍可能看到很高尖峰。

# 【二】工作原理与保护链路

## 【1】从正常状态到雪崩钳位

```text
正常工作：信号/电源电压 < V_RWM，TVS 漏电很小
瞬态来临：电压超过 V_BR，TVS 进入雪崩导通
钳位阶段：浪涌电流经 TVS 回流，后级电压受限于 V_C 加寄生尖峰
```

TVS 响应本身很快，但“皮秒级保护”不应当作系统设计结论。ESD 电流边沿极快，几毫米走线电感就会产生显著电压；连接器到 TVS、TVS 到地/回流面的路径必须极短。

## 【2】典型连接

```text
外部连接器 ──●──── 串联阻抗/共模器件 ──── 被保护 IC
               │
              TVS
               │
             GND / 机壳地

TVS 靠近连接器；被保护 IC 在 TVS 的“后方”
```

串联电阻、磁珠、共模电感和限流器件可降低流入后级的剩余能量，但会影响信号带宽/压降；它们与 TVS 必须作为一个保护网络共同设计。

# 【三】关键参数与正确关系

| 参数 | 含义 | 选型要点 |
| --- | --- | --- |
| `V_RWM` | 最大反向工作电压 | 必须高于正常工作电压的最高值（含容差/浪涌） |
| `V_BR` | 击穿电压 | 在指定测试电流 `I_T` 下测得，不是最终钳位电压 |
| `V_C` | 钳位电压 | 在指定峰值电流 `I_PP` 下的最大值，需低于后级可承受范围 |
| `I_PP` | 峰值脉冲电流 | 只对规定脉冲波形和温度有效 |
| `P_PPM` | 峰值脉冲功率 | 通常近似 `V_C × I_PP`，必须注明测试波形 |
| `C_J` | 结电容 | 高速数据线要低电容，电源线通常可更高 |
| 漏电流 | 正常工作时的泄漏 | 低功耗/高阻传感器/电池系统特别重要 |

`V_RWM`、`V_BR`、`V_C` 不能互相替代：`V_RWM` 决定正常时不应误导通，`V_C` 才决定浪涌时后级实际可能面对的电压。

# 【四】单向、双向与阵列器件

## 【1】极性选择

| 类型 | 特性 | 常见用途 |
| --- | --- | --- |
| 单向 TVS | 正向类似二极管导通，反向雪崩钳位 | 单极性直流电源、单端信号（按极性连接） |
| 双向 TVS | 正负两向对称钳位 | 交流、双向信号、某些差分/音频线路 |
| TVS 阵列 | 多通道、可集成导流/共模结构 | USB、HDMI、键盘、以太网等接口 |

“双向 TVS 一定适合差分高速线”并不正确：还需看每线对地/线间的结构、结电容、动态电阻和 IEC 测试等级。USB 2.0/3.x、HDMI、以太网等要优先选专为该接口设计的低电容阵列。

## 【2】脉冲能力与波形

TVS 的 400 W、600 W、1500 W 等额定值通常基于 10/1000 µs 等特定浪涌波形。ESD（IEC 61000-4-2）、汽车 load dump、雷击浪涌（IEC 61000-4-5）的能量和波形完全不同，不能直接拿“1500 W”判断所有场景都安全。

# 【五】选型步骤

## 【1】先从被保护对象反推

1. 明确接口正常最高电压、最大允许泄漏和信号速率；
2. 查后级芯片的绝对最大额定值、内置钳位能力与允许注入电流；
3. 选择 `V_RWM` 高于正常最大电压的 TVS；
4. 在目标浪涌电流与布局寄生条件下，确认 `V_C` 加剩余尖峰仍低于后级可承受电压；
5. 核对 `I_PP / P_PPM` 与实际浪涌标准、温度降额和重复次数；
6. 对高速接口再核对结电容、差分阻抗、插损与布局参考设计。

## 【2】电源与数据线的差异

| 场景 | 优先指标 | 常见搭配 |
| --- | --- | --- |
| 12/24 V 电源入口 | `V_RWM`、浪涌能力、钳位、热 | TVS + 保险丝/PTC + 反接/浪涌保护 |
| MCU GPIO 外部线 | 漏电、钳位、串联限流 | 低电容 TVS + 串阻 + 合理钳位 |
| USB/高速差分线 | 极低电容、低插损、对称性 | 专用多通道 ESD 阵列 |
| CAN/RS-485 | 工作电压、共模浪涌、总线电容 | 总线专用 TVS + 端接/共模设计 |

# 【六】布局、失效与测试

## 【1】布局优先级

```text
正确的物理顺序：连接器 → TVS → 串联/滤波 → 收发器或 MCU

错误的物理顺序：连接器 → 长走线 → IC → 远处 TVS
```

- TVS 到地平面的过孔/焊盘路径应短、宽、直接，必要时多过孔并联；
- 不要让被保护 IC 的走线先经过很长一段再分支到 TVS；
- 外壳地、保护地与数字地的连接策略应按 EMC/安规整体确定；
- TVS 可能在多次大能量脉冲后参数劣化甚至短路/漏电增大，不能认为“无老化问题”。

## 【2】常见错误

- 只看 `V_BR`，不看 `V_C` 及其对应 `I_PP`；
- 只按常态电压选 `V_RWM`，忽略电源容差、插拔尖峰和车载 load dump；
- 用高电容电源 TVS 保护高速 USB/HDMI，导致通信不稳定；
- TVS 离连接器很远，地回路又细又长；
- 将 TVS 当作持续过压稳压器或保险丝，导致长期发热、击穿失效。

测试保护能力必须在受控实验条件下按相应标准进行。普通台式万用表和示波器无法替代 ESD 枪、浪涌发生器及正确的测试夹具；带高压浪涌的验证应由具备安全条件的人员完成。
