# 【一】晶体、振荡器与系统时钟

工程中常把“晶振”泛指时钟器件，但要区分：**无源晶体（crystal/resonator）**本身是谐振器，需与 MCU/外部振荡放大器组成振荡电路；**有源振荡器模块（XO）**内部已包含晶体和振荡电路，供电后直接输出时钟。

![常见石英晶体与有源振荡器外观](https://oss.silentdream.top/2026/10/02/01-12-28-cea53d08-image-20261001224753625-deca10.png)

时钟影响 MCU 指令周期、UART 波特率、USB 时序、RTC 走时、无线协议和 ADC 采样。系统“能启动”并不代表时钟准确：频率偏差、抖动、温漂和启动裕量都可能造成间歇性通信故障。

# 【二】结构与压电谐振原理

石英晶体利用压电效应：施加电场会使晶片机械形变；机械振动反过来也会产生电信号。在特定共振频率附近，晶体表现出很高的 Q 值，振荡电路从中选出稳定频点。

![石英晶体结构示意](https://oss.silentdream.top/2026/10/02/01-12-28-acea8a3c-image-20261001224938895-175312.png)

```text
无源晶体： 石英谐振器 + MCU 内部反相放大器 + 外部负载电容
有源振荡器：石英谐振器 + 内部振荡/缓冲电路 + 电源 → 时钟输出
```

> **纠正概念**：有源振荡器不一定使用“运放”，无源晶体也不是“无需能量即可输出时钟”。无源晶体本身不供电，但整个振荡回路仍由 MCU 内部振荡器或外部放大器提供能量。

# 【三】频率、精度与关键参数

## 【1】常见频率

| 频率 | 常见用途 | 说明 |
| --- | --- | --- |
| 32.768 kHz | RTC、低功耗计时 | 每秒 2¹⁵ 个周期，便于二进制分频 |
| 8 / 12 / 16 / 24 MHz | MCU 外部高速时钟 | 具体频率受芯片/协议要求限制 |
| 12 / 24 / 25 / 26 MHz | USB、以太网、射频相关时钟 | 通常有较严的频偏/抖动要求 |
| 数十至数百 MHz | 通信、FPGA、高速系统 | 常用有源 XO、TCXO、差分时钟 |

## 【2】数据手册必须核对的参数

| 参数 | 含义 | 选型要点 |
| --- | --- | --- |
| 标称频率 | 目标共振/输出频率 | 必须符合芯片振荡器与协议要求 |
| 初始频偏 | 出厂频率误差，常用 ppm | UART/USB/无线链路要核算总误差预算 |
| 温度稳定度 | 温度范围内频率变化 | 户外、工业、RTC 特别重要 |
| 老化率 | 长期频率漂移 | 长寿命计时/通信设备需关注 |
| 负载电容 CL | 指定测试与工作条件 | 与外部 C1/C2 共同决定实际频偏 |
| ESR | 等效串联电阻 | 不能超过 MCU 振荡器允许的最大值 |
| 驱动电平 | 允许激励功率 | 过驱会加速老化甚至损坏晶体 |
| 启动时间 | 从上电到稳定振荡的时间 | 影响复位、低功耗唤醒与时钟切换 |

# 【四】有源与无源的选择

## 【1】有源振荡器（XO）

有源 XO 需要电源，输出 CMOS、LVCMOS、LVDS、HCSL 等指定逻辑时钟。它接线简单、驱动能力强、频率选择多，适合多负载、长距离或高速时钟。

```text
VCC ──→ XO VDD
GND ──→ XO GND
XO OUT ── 串联小电阻（可选）──→ 芯片时钟输入
```

应核对供电电压、输出标准、占空比、启动时间、抖动、输出使能脚与目标芯片的输入范围。未使用的使能脚不得悬空。

## 【2】无源晶体（Crystal）

无源晶体通常成本低、功耗小、接近 MCU 放置即可工作，但必须和 MCU 推荐的振荡器模式、外部电容和布局配合。

```text
             ┌── 晶体 ──┐
MCU OSC_IN ──●          ●── MCU OSC_OUT
             │          │
             C1         C2
             │          │
            GND        GND
```

# 【五】无源晶体电路与负载电容

![无源晶体的典型 MCU 连接](https://oss.silentdream.top/2026/10/02/01-12-28-74997587-image-20261001225254327-bd7b37.png)

对常见 Pierce 振荡器，晶体看到的等效负载电容可粗略估算为：

$$
C_L\approx\frac{C_1C_2}{C_1+C_2}+C_{stray}
$$

其中 `C_stray` 包含 MCU 引脚、PCB 和封装寄生电容。若 `C1 = C2 = C`，则外部电容近似可从 `C ≈ 2 × (CL − Cstray)` 开始估算；最终以 MCU 和晶体手册推荐值及实测频偏为准。

电容并非越大越好：过大会增大驱动负担、降低启动裕量并改变频偏；过小又可能导致频率偏差或抗干扰不足。

# 【六】布局、测量与失效排查

## 【1】布局规则

- 晶体、C1、C2 靠近 MCU OSC 引脚，连接短、对称、少过孔；
- 晶振区域下方避免高速数字线、开关节点和大电流回路，按芯片建议处理地铜；
- 负载电容直接、短路径接到安静地；不要与电机/蜂鸣器/开关电源回流共用细长地线；
- 不要在晶体引脚上随意挂测试点、长飞线或其他负载。

## 【2】测量与常见问题

高阻抗晶振节点很敏感。普通 ×1 探头的大电容足以让振荡停振或移频；优先使用高阻抗、低电容 ×10/有源探头，或从 MCU 提供的时钟输出脚间接测量。

| 现象 | 常见原因 | 排查方向 |
| --- | --- | --- |
| MCU 不启动/时钟故障 | 晶体频率或模式错误、C 值不当、焊接不良 | 查启动脚、替换晶体、核对手册 |
| UART 波特率偏差大 | 内部 RC 偏差或晶体频偏 | 测时钟、核算 ppm 预算 |
| 低温/高温偶发停振 | ESR/驱动裕量不足、器件温度规格不足 | 查最大 ESR、驱动电平与温漂 |
| 加探头后异常 | 探头负载改变振荡器 | 改用低电容探头/间接测量 |
