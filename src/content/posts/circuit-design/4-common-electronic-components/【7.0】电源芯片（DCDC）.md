# 【一】DC-DC：高效率的直流电压变换

DC-DC 转换器通过开关管、电感/变压器、二极管或同步 MOSFET 和控制环路，在不同直流电压之间高效率地传递能量。与 LDO 相比，它通常效率高、发热小，但外围、布局、EMI 和稳定性设计更复杂。

![DC-DC 转换器与常见应用示意](https://oss.silentdream.top/2026/10/02/01-12-28-245bd391-image-20261001231207449-09d207.png)

```text
Vin ── 开关管 ── 电感/变压器 ── 整流/同步管 ── Cout ── Vout
                  ↑                                 │
                  └──────── 控制器根据反馈调节 ──────┘
```

# 【二】常见拓扑与工作直觉

## 【1】降压型 Buck

Buck 把较高输入电压降为较低输出电压。开关导通时电感储能，关断时电感经续流二极管或同步 MOSFET 向负载继续供能。

```text
Vin ── SW ──●── L ──●── Vout
            │        │
         二极管/     Cout
         同步 MOS     │
            │       GND
           GND
```

理想连续导通模式下，输出与占空比关系近似为：

$$
V_{OUT}\approx D\times V_{IN}
$$

## 【2】升压型 Boost

Boost 把较低输入电压升为较高输出电压。开关导通时电感储能；开关关断时，电感电压与输入叠加，经二极管/同步管送到输出。

$$
V_{OUT}\approx\frac{V_{IN}}{1-D}
$$

升压不能主动把输出降到低于输入；当输入与输出连接路径存在时，关断状态下仍可能有输入到输出的通路，设计电源时必须考虑关机漏电与预偏置。

## 【3】Buck-Boost 与反相拓扑

Buck-Boost 可在输入高于或低于目标输出时稳定输出，适合锂电池等宽输入场景；反相拓扑提供负电压。不同芯片的“Buck-Boost”可能是反相、四开关非反相、SEPIC 等不同结构，不能仅按名称套公式或复制外围。

# 【三】为什么 DC-DC 效率高但更难设计

## 【1】损耗来源

| 损耗 | 来源 | 常见改善方式 |
| --- | --- | --- |
| 导通损耗 | MOSFET `I²R`、电感 DCR、二极管压降 | 低 RDS(on)、低 DCR、同步整流 |
| 开关损耗 | 开通/关断重叠、栅极驱动 | 合理开关频率、优化驱动/布局 |
| 磁芯损耗 | 电感高频磁化 | 合适磁材、频率和电感量 |
| 电容损耗 | ESR 与纹波电流 | 选择合适低 ESR、足够纹波能力 |
| 控制器静态电流 | 轻载/待机消耗 | 低 IQ 芯片、PFM/省电模式 |

## 【2】开关频率的取舍

频率提高可减小电感和电容体积，但会增加开关损耗和 EMI；频率降低通常效率更好、元件更大。不能只为了“小”而无限提高频率，也不能只凭经验替换参考设计中的电感。

# 【四】关键器件与选型

## 【1】电感与电容

电感量、饱和电流、RMS 电流和 DCR 都重要。电感饱和后电感量骤降，峰值电流可能失控上升；电感 `I_sat` 必须高于最坏情况下的峰值电流并留余量。

输入电容承担高脉冲电流，必须紧贴 VIN/GND 回路；输出电容影响纹波、环路稳定和瞬态响应。容量、耐压、ESR、纹波电流与 DC Bias 特性都要核对。

## 【2】芯片参数

| 参数 | 关注点 |
| --- | --- |
| 输入电压范围 | 启动、稳态、浪涌与绝对最大值均要满足 |
| 输出电流 | 看热限制、峰值开关限流和电感能力，而非宣传最大值 |
| 开关频率/模式 | PWM、PFM、强制 PWM 对效率、纹波和 EMI 的影响 |
| 反馈基准/补偿 | 决定输出分压与环路稳定性 |
| 同步整流 | 轻载效率、反向电流与布局要求可能不同 |
| 保护 | UVLO、OCP、OVP、OTP、短路模式与自动重启行为 |

## 【3】LM2596 与 TPS5430 的使用边界

LM2596 是较早的 150 kHz 非同步 Buck 系列，常见标称开关电流能力较高，但模块实际连续输出能力受二极管、电感、散热和输入条件限制。TPS5430 是 500 kHz、3 A 级 Buck 控制器/转换器系列，具体参数依版本和应用条件而异。它们都是**具体芯片**，外围电感、二极管、补偿/反馈网络必须按各自数据手册和评估板设计，不能互换。

# 【五】布局：成败的关键

## 【1】最小化高 di/dt 回路

```text
Buck 的关键热回路：
输入电容正端 → 高侧开关 → SW 节点 → 低侧续流器件 → 输入电容负端

该回路必须：短、宽、紧凑；SW 铜皮不宜过大。
```

- 输入电容贴近芯片 VIN 与功率地；
- 电感、二极管/同步管、输出电容按官方布局紧凑摆放；
- 反馈分压从输出电容安静端取样，远离 SW 节点和电感磁场；
- 功率地与信号地按手册推荐方式汇合，避免大电流回流污染反馈地；
- 开关节点远离晶振、ADC、天线、高阻传感器和 USB 差分线。

## 【2】EMI 与测量

DC-DC 的尖峰来自寄生电感、电容与快速开关边沿。示波器若用长地夹测 SW 节点，常会测出夸大的“假振铃”；应使用短地弹簧或差分探头。需要通过 EMC 时，输入滤波、屏蔽、开关频率规划和 PCB 回路控制要整体处理。

# 【六】调试与常见故障

| 现象 | 常见原因 | 首先检查 |
| --- | --- | --- |
| 无输出 | EN/UVLO 未满足、反馈接错、芯片焊接错误 | EN、VIN、FB 与 GND |
| 输出过高 | 反馈分压错、FB 断线 | FB 电压、R 上下臂数值/焊接 |
| 带载掉压/啸叫 | 电感饱和、限流、输入供电不足 | 峰值电流、电感温度、VIN 波形 |
| 纹波/尖峰大 | Cin/Cout 布局差、ESR/容量不当 | 电容位置、短地测量、回路面积 |
| 芯片/电感过热 | 损耗大、散热不足、二极管压降高 | 效率、温升、DCR、开关波形 |

首次上电建议使用可限流电源，从低输入电压、轻载开始，先确认空载输出和启动波形，再逐步增加负载。不要直接把昂贵 MCU 板接到未经验证的开关电源输出。
