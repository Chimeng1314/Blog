# 【一】继电器：小信号控制大功率回路

继电器是通过线圈、触点或半导体开关实现电路通断的器件。电磁继电器可用低压控制侧切换与之电气隔离的负载侧，适合交流/直流负载、不同电平系统以及需要物理断开的场景。

![常见电磁继电器实物](https://oss.silentdream.top/2026/10/02/01-12-28-9b8e3f7a-image-20261001224202038-6b0475.png)

> **安全提示**：继电器触点切换市电并不等于整机安全。保险丝、阻燃材料、爬电距离、端子防护、浪涌抑制和外壳绝缘都需要按相应标准设计；不要在带电状态下手持或改接市电继电器板。

# 【二】基本结构与触点术语

![继电器线圈、铁芯与触点结构](https://oss.silentdream.top/2026/10/02/01-12-28-3b17175a-image-20261001224400180-59c0f5.png)

电磁继电器一般包括线圈、铁芯/衔铁、复位弹簧和触点。线圈通电产生磁场，吸合衔铁改变触点状态；线圈断电后由弹簧复位。

```text
线圈未通电：COM ── NC 接通，NO 断开
线圈已吸合：COM ── NO 接通，NC 断开

COM：公共端    NO：常开触点    NC：常闭触点
```

“常开/常闭”描述的是**线圈未通电时**的状态，不描述负载当前是否有电。触点形式还会标为 SPST-NO、SPST-NC、SPDT（转换型）及 DPDT 等。

# 【三】类型与适用范围

| 类型 | 特点 | 常见用途 |
| --- | --- | --- |
| 电磁继电器 | 触点隔离、可切 AC/DC、多数有机械声 | 通用负载、控制柜 |
| 簧片继电器 | 小型、低信号泄漏、寿命较高 | 测试仪器、低电平切换 |
| 固态继电器 SSR | 无机械触点、寿命和速度好 | 高频动作、交流加热控制 |
| 时间继电器 | 按延时逻辑动作 | 顺序控制、定时启停 |
| 热继电器 | 用热效应保护电机过载 | 电机保护，非通用开关 |

SSR 有交流型和直流型，交流 SSR 常用可控硅/双向可控硅，存在关断漏电流和过零/随机导通区别；直流负载不能随意使用交流 SSR。

# 【四】驱动电路与续流保护

## 【1】MCU 不能直接推线圈的原因

继电器线圈吸合电流常为数十到数百 mA，远超多数 GPIO 允许值；断电瞬间线圈还会产生感应电压。推荐使用三极管或 N-MOS 低端开关：

```text
VCC ── 继电器线圈 ──●── N-MOS / NPN ── GND
                      │
                      └──|<|── VCC
                         续流二极管：正常反偏，关断时导通

MCU GPIO ── R_G/R_B ── 控制端
控制端 ── 下拉电阻 ── GND
```

续流二极管限制关断尖峰、保护开关管，但会使线圈电流衰减较慢，继电器释放时间变长。若需要更快释放，应使用 TVS/齐纳钳位或专用驱动，重新校核 MOSFET 耐压、EMI 和发热。

## 【2】线圈侧和触点侧要分开看

- **线圈侧**：看额定线圈电压、线圈电阻、吸合/释放电压、线圈功耗和驱动器；
- **触点侧**：看负载电压、电流、AC/DC 类型、浪涌、功率因数和开断次数；
- 线圈额定 5 V、触点标 10 A/250 VAC 并不表示“任何 10 A 负载都能安全切换”。

# 【五】触点负载、寿命与抑制

![继电器控制负载的接线示例](https://oss.silentdream.top/2026/10/02/01-12-28-0b454796-image-20261001224543226-c1c4de.png)

电阻性负载（加热丝、白炽灯稳态）较易开断；电机、变压器、电磁阀等感性负载在断开时会产生电弧，触点更易烧蚀和粘连；灯泡、电容输入电源则有很高的启动浪涌。

```text
触点 ── 感性 AC 负载：可考虑 RC 吸收或 MOV（按电压与认证选型）
触点 ── 感性 DC 负载：负载两端可考虑续流二极管/TVS
```

![继电器模块/触点连接示意](https://oss.silentdream.top/2026/10/02/01-12-28-1c59d33b-image-20261001224550554-fd6b42.png)

> **读图提示**：模块板上的 `IN`、`VCC`、`GND` 与 `COM/NO/NC` 属于两个不同区域。模块是否“低电平触发”、是否真正光耦隔离、能否使用独立 JD-VCC，必须以具体板卡原理图确认。

# 【六】选型、布局与排错

## 【1】关键参数

| 参数 | 说明 | 选型要点 |
| --- | --- | --- |
| 线圈额定电压/功耗 | 驱动侧条件 | 保证最差供电下能吸合，连续通电不过热 |
| 吸合/释放电压 | 动作阈值范围 | 电池系统压降、温度下仍要可靠动作 |
| 触点额定值 | 指定负载下的开断能力 | 必须匹配 AC/DC、阻性/感性、浪涌 |
| 绝缘/耐压 | 线圈与触点、触点间隔离 | 高压设计与 PCB 安全距离一起审查 |
| 电气/机械寿命 | 实际可动作次数 | 电气寿命通常远低于机械寿命 |
| 吸合/释放时间 | 动作速度 | PWM、高频切换通常不适合机械继电器 |

## 【2】常见故障

- 线圈有声但负载不通：触点接错 COM/NO/NC、触点烧蚀、负载侧无电；
- MCU 一吸合就复位：线圈电流造成电源跌落、地回流共阻抗或未加续流；
- 触点焊死：感性负载电弧、浪涌过大、选型未按负载类别降额；
- 继电器频繁吸合释放：驱动电压不足、控制信号抖动、电源容量不足；
- 用继电器 PWM 调速：机械寿命、响应速度和电弧问题都会迅速恶化，应使用 MOSFET/专用驱动。
