# 【一】标准IO的理解

## 【1】IO的理解

- I : input , 读, 输入, 接收

- O : output , 写, 输出, 发送

## 【2】标准IO库

- 标准IO库是C语言的标准库。

- 不仅在Linux系统，在很多操作系统上都实现了标准I/O库。

- 标准I/O库由ANSI C标准说明 ,  是C语言的标准库

- 标准I/O库处理很多细节，如缓存分配、以优化长度执行I/O等，这样使用户不必关心如何选择合适的块长度。

- 标准I/O在系统调用(文件IO)函数基础上构造的，它便于用户使用。

- 标准I/O库及其头文件stdio.h为底层I/O系统调用提供了一个通用的接口。

## 【3】文件指针

- `FILE *` 是 C 标准库用于管理流的指针，关联缓冲区、读写位置及错误状态等信息；它不是内核的文件描述符。

- 下面保留 glibc 历史实现的结构片段用于理解，不能作为完整定义直接编译，也不要在应用中访问这些内部字段：

- 标准I/O库的所有操作都是围绕流(stream)来进行的，在标准I/O中，**流用FILE \*来描述**。

- 标准I/O库是由Dennis Ritchie在1975年左右编写的。

## 【4】流（stream）

### （1）定义

- 所有的I/O操作仅是简单的从程序移进或者移出，这种字节流，就称为流。


### （2）分类

- 文本流

- 二进制流


### （3）文本流

- 定义：在流中处理的数据是以字符出现。
- 文本模式可能转换换行表示：Linux 中通常直接使用 LF（`0x0A`），Windows 的 C 运行库通常在 `\n` 与 CRLF 之间转换。

- 数字2001在文本流中的表示方法为 `2`、`0`、`0`、`1`

  - ASCII:  `50` `48` `48` `49`


### （4）二进制流

- 定义：流中处理的是二进制序列。

- 二进制流按字节读写，不做文本模式的换行转换。写入的数据表示由程序决定。

- `2001` 的十六进制值是 `0x07D1`；若按 16 位整数存储，大端字节序为 `07 D1`，小端为 `D1 07`。直接写 C 整数时还依赖类型宽度与主机字节序，不能假定只有两个字节。

## 【5】缓冲文件系统(高级磁盘IO)

### （1）目的

- 尽量减少使用read/write的调用。


### （2）定义

- C 标准库为流维护用户态缓冲区，写入可先进入缓冲区，在缓冲区满、主动刷新或关闭流等时机交给底层系统调用；刷新并不保证数据已经持久化到磁盘。

- 从磁盘中读数据，则一次从磁盘文件将一批数据读入到内存缓冲区中，然后再从缓冲区逐个的将数据送到程序的数据区。

- 类比景区的摆渡车


### （3）分类

- 全缓存，行缓存，不缓存。

## 【6】非缓冲文件系统 （低级磁盘IO）

- 依靠于操作系统，通过操作系统的功能对文件进行读写，是系统级的输入输出。

- 这里的“非缓冲”指不经过 C 标准 I/O 的用户态缓冲；`read` / `write` 仍可能使用内核页缓存，不等同于 Linux 的 `O_DIRECT`。

- 类比城市的公交车

## 【7】标准I/O (stdin,stdout,stderr)

- 标准I/O预定义3个流，他们可以自动地为进程所使用。

![标准输入、标准输出与标准错误流示意图](https://oss.silentdream.top/2026/10/17/21-03-47-9f04c2db-page-003-img-01-de55bf.png)

- `stdin`    :  标准输入

- `stdout`   : 标准输出

- `stderr`   : 标准错误

# 【二】打开流 `fopen`

## 【1】函数原型(函数的声明)

```c
FILE *fopen(const char *pathname, const char *mode);
```

## 【2】函数的功能

- 打开一个文件 , 并返回一个流(文件指针)

## 【3】函数的参数

- pathname : 要打开的文件名 , 例如`/home/linux/1.txt`

- mode : 打开文件的方式

| 打开方式     | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| b            | binary的缩写, 表示以二进制的形式打开文件, 操作的是二进制流   |
| r或rb        | 打开只读文件，该文件必须存在，文件不存在报错。               |
| r+或r+b      | 打开可读写的文件，该文件必须存在。                           |
| w或wb        | 打开只写文件，若文件存在则文件长度清为0，即会擦除文件以前内容。若文件不存在则建立该文件。 |
| w+或w+b或wb+ | 打开可读写文件，若文件存在则文件长度清为零，即会擦除文件以前内容。若文件不存在则建立该文件。 |
| a或ab        | 以附加的方式打开只写文件。若文件不存在，则会建立该文件， 如果文件存在，写入的数据会被加到文件尾，即文件原先的内容会被保留。 |
| a+或a+b或ab+ | 以附加方式打开可读写的文件。若文件不存在，则会建立该文 件，如果文件存在，写入的数据会被加到文件尾后，即文件原先 的内容会被保留。 |

## 【4】函数返回值

- 成功返回  :  FILE 类型的指针(内存中创建的结构体首地址)

- 失败返回  :  NULL指针并设置errno, 设置errno后可以使用perror 打印出错信息

# 【三】关闭流 `fclose`

## 【1】函数原型

```c
int fclose(FILE *stream);
```

## 【2】函数功能

- 关闭一个已经打开的文件(流)

## 【3】函数参数

- stream : 要关闭文件的流

## 【4】函数返回值

- 成功返回:  返回为0

- 失败返回 : EOF(end of file) , 并设置errno

## 【5】练习-进程可以打开文件个数

- 进程可打开的文件描述符数量受 `RLIMIT_NOFILE` 限制，可在 Shell 中用 `ulimit -n` 查看软限制；1024 只是下面实验环境的配置。

- 本地终端与 SSH 会话都能运行该实验，但继承的资源限制可能不同。请在独立临时目录中执行，程序会创建大量空文件。

![循环打开文件触发 Too many open files 的终端记录](https://oss.silentdream.top/2026/10/17/21-03-47-ebc5999d-page-006-img-01-1585ce.png)

```c
#include <stdio.h>
int main(void)
{
    // 声明文件指针
    FILE *fp = NULL;
    // 声明计数变量
    int i = 0;
    // 声明文件名数组
    char filename[128];

    // 循环打开文件
    while (1)
    {
        // 生成文件名
        sprintf(filename, "file%d", i);

        // 打印文件名
        printf("filename: %s\n", filename);

        // 只打开文件，文件不存在则创建新文件，文件存在则清空文件内容
        fp = fopen(filename, "w");
        // 打开文件失败会提示错误信息
        if (fp == NULL)
        {
            perror("fopen");
            return -1;
        }
        // 不 关闭文件 , 测试一个进程最多可以打开多少个文件
        // fclose(fp);

        // 计数增加
        i++;
    }

    return 0;
}
```

# 【四】读写流 `fgetc`/`fgets`/`fread`

- 调用fopen()成功打开流之后，可在三种不同类型的非格式化I/O中进行选择，对其进行读、写操作:

- **每次一个字符的I/O**。使用`fgetc()`/`fputc()`一次读或写一个字符，如果流是带缓存的，则标准I/O函数处理所有缓存。

- **每次一行的I/O**。使用`fgets()`和`fputs()`一次读或写一行。每行都以一个新行符终止。当调用`fgets()`时，应说明能处理的最大行长。

- **块 I/O**。`fread()`和`fwrite()`函数支持这种类型的I/O。每次I/O操作读或写某种数量的对象，而每个对象具有指定的长度。这两个函数常用于从二进制文件中读或写一个结构，并不表示绕过标准 I/O 缓冲。

## 【1】每次读一个字符 `fgetc`

### （1）函数原型

```c
int fgetc(FILE *stream);
```

### （2）函数功能

- 从已经打开的流(文件指针)中读取一个字符

### （3）函数参数

- stream : 要读文件的流

### （4）函数返回值

- 成功返回:  返回读回来的字符

- 失败返回 : EOF(end of file)

### （5）练习-使用`fgetc`实现`cat`

```c
#include <stdio.h>
int main(int argc, char const *argv[])
{

    // cat c 需要 一个源文件 名参数
    if (argc != 2)
    {
        printf("Usage: %s filename\n", argv[0]);
        return -1;
    }

    // 读一个文件打开 ， 声明一个文件指针指向这个文件
    FILE *fp = fopen(argv[1], "r");

    // 判断打开的文件是否有效
    if (fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    // 每次从文件中读一个字符 fgetc
    int ch; // 保留所有 unsigned char 值，并能区分 EOF
    // 读取到文件结束符 EOF 时，结束循环
    while ((ch = fgetc(fp)) != EOF)
    {
        // 打印读取到的每一个字符
        printf("%c", ch);
    }

    fclose(fp);
    return 0;
}

```

## 【2】每次写一个字符 `fputc`

### （1）函数原型

```c
int fputc(int c, FILE *stream);
```

### （2）函数功能

- 把一个字符写入到一个已经打开的流(文件指针)中

### （3）函数参数

- c : 要写入文件的字符

- stream : 要写文件的流

### （4）函数返回值

- 成功返回:  返回写入文件的字符

- 失败返回 : EOF(end of file)

### （5）练习-`fputc`和`fgetc`实现`cp`

```c
#include <stdio.h>
int main(int argc, char const *argv[])
{

    // cp 需要 一个源文件 需要一个目标参数
    if (argc != 3)
    {
        printf("Usage: %s source target\n", argv[0]);
        return -1;
    }

    // 读一个文件打开 ， 声明一个文件指针指向这个文件
    FILE *fp_src = fopen(argv[1], "rb");
    if (fp_src == NULL)
    {
        perror("fopen");
        return -1;
    }

    // 写一个文件打开 ， 声明一个文件指针指向这个文件，文件不存在会新建
    FILE *fp_dst = fopen(argv[2], "wb");
    // 判断打开的文件是否有效
    if (fp_dst == NULL)
    {
        perror("fopen");
        // 关闭有问题的源文件
        fclose(fp_src);
        return -1;
    }

    // 每次从文件中读一个字符 fgetc
    // 已经读了一个字符了
    int ch; // 保留所有 unsigned char 值，并能区分 EOF
    // 读取到文件结束符 EOF 时，结束循环
    while ((ch = fgetc(fp_src)) != EOF)
    {
        // 写入目标文件
        fputc(ch, fp_dst);
    }

    // 关闭文件1 和 文件2
    fclose(fp_src);
    fclose(fp_dst);

    return 0;
}
```

## 【3】每次读一行的字符串 `fgets`

### （1）函数原型

```c
char *fgets(char *s, int size, FILE *stream);
```

### （2）函数功能

- 从流(文件指针)读取指定长度的字符串到s指定的内存中

- 当 `size > 1` 时，从 stream 最多读入 `size - 1` 个字符到 s；遇到文件末尾或读入换行符后停止。换行符会被保留，成功读取后在末尾补上 `\0`。

- 一行超过缓冲区容量时，需要多次调用 `fgets` 才能读完；它不会保证每次返回完整的一行。

### （3）函数参数

- s :  保存读回来的字符串的内存地址

- size : 要读多少个字节

- stream : 要读文件的流

### （4）函数返回值

- 成功返回:  返回保存字符串的内存地址s

- 失败返回 : 错误时返回NULL, 或者是到达文件末尾时也返回NULL

### （5）练习-`fgets`实现`cat`

```c
#include <stdio.h>
int main(int argc, char const *argv[])
{

    // fgets 实现 cat 功能 需要 一个源文件
    if (argc != 2)
    {
        printf("Usage: %s filename\n", argv[0]);
        return -1;
    }

    // 打开一个文件流
    FILE *fp = fopen(argv[1], "r");
    if (fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    // 读取文件内容 以 每行的形式读取
    char buffer[1024] = {0};
    // 读取文件内容 以指定的字节数读取 直至文件结束
    while (fgets(buffer, sizeof(buffer), fp) != NULL)
    {
        printf("%s", buffer);
    }

    // 读取结束关闭文件
    fclose(fp);

    return 0;
}
```

## 【4】每次写一行的字符串 `fputs`

### （1）函数原型

```c
int fputs(const char *s, FILE *stream);
```

### （2）函数功能

- 把s保存的字符串写入到流(文件指针)内

### （3）函数参数

- s :  要写入流内的字符串

- stream : 要写文件的流

### （4）函数返回值

- 成功返回：非负值，不保证等于写入的字节数；`fputs` 不会自动追加换行符。

- 失败返回 : 错误时返回EOF

### （5）练习-使用`fgets`和`fputs`实现`cp`

```c
#include <stdio.h>
int main(int argc, char const *argv[])
{

    // fgets + fputs 实现 cp 功能 需要 一个源文件 一个目标文件
    if (argc != 3)
    {
        printf("Usage: %s source target\n", argv[0]);
        return -1;
    }

    // 打开读的源文件
    FILE *fp_src = fopen(argv[1], "rb");
    if (fp_src == NULL)
    {
        perror("fopen");
        return -1;
    }

    // 打开写的源文件
    FILE *fp_dst = fopen(argv[2], "wb");
    if (fp_dst == NULL)
    {
        perror("fopen");
        // 如果打开写的文件有问题关闭源文件
        fclose(fp_src);
        return -1;
    }

    // 定义缓冲区
    char buffer[1024] = {0};
    // 读取文件内容 以指定的字节数读取 直至文件结束
    while (fgets(buffer, sizeof(buffer), fp_src) != NULL)
    {
        // 写入文件内容 以指定的字节数写入 直至文件结束
        fputs(buffer, fp_dst);
    }

    // 关闭文件
    fclose(fp_src);
    fclose(fp_dst);

    return 0;
}
```

## 【5】直接读指定字节数 `fread`

### （1）函数原型

```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
```

### （2）函数功能

- 从流(文件指针)中读取指定字节数保存到ptr所指向的内存

- 可以读文本文件，也可以读二进制文件。

- `fgetc` 也可逐字节读取二进制流；`fgets` 按换行读取，配合字符串函数处理时会受到内嵌 `\0` 的影响，因此不适合通用二进制复制。

### （3）函数参数

- ptr :  要保存数据的内存地址

- size :  每一个元素的字节数

- nmemb: 要读取元素的个数

- stream : 要读文件的流

### （4）函数返回值

- 返回实际完整读取的元素个数，只有 `size == 1` 时才等于字节数。

- 失败返回 :

  - 遇到文件末尾或错误时，可能返回小于 nmemb 的非零值，也可能返回 0；通过 `feof` / `ferror` 区分。

### （5）练习-`fread`实现`cat`

```c
#include <stdio.h>
int main(int argc, char const *argv[])
{

    // fread 实现 cat 功能 需要一个源文件 名参数
    if (argc != 2)
    {
        printf("Usage: %s source\n", argv[0]);
        return -1;
    }

    // 打开源文件
    FILE *fp_src = fopen(argv[1], "rb");
    if (fp_src == NULL)
    {
        perror("fopen");
        return -1;
    }

    // 读取源文件的对应的内容
    char buffer[1024] = {0};
    // 到达文件末尾返回 0 / 错误时返回 0
    /**
    size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
        - ptr :  要保存数据的内存地址
        - size :  每一个元素的字节数
        - nmemb: 要读取元素的个数
        - stream : 要读文件的流
     */
    while (fread(buffer, 1, 128, fp_src) != 0)
    {
        printf("%s", buffer);
    }

    // 这里会有一个问题， 读取到的最后一个字符会乱码
    // 使用清除数组内容的办法， 不能彻底解决乱码的问题， 最终还是需要使用fwrite

    // 关闭文件
    fclose(fp_src);

    return 0;

```

这个程序是错误用法演示：`fread` 不会追加字符串结束符，`printf("%s", buffer)` 可能输出上次遗留数据；缓冲区装满时还可能越界读取。应按实际读取长度使用 `fwrite`。

- 清空数组不能解决二进制内容含 `\0` 或缓冲区刚好填满的问题，正确写法见下一节。

# 【五】定位流 ftell/fseek

## 【1】定位标准I/O流的两种方式

- 文件的位置可以理解为文件的光标的位置

- `ftell()`和`fseek()`: 这两个函数自V7以来就存在了，但是它们都假定文件的位置可以存放在一个**长整型**中。

- `fgetpos()`和`fsetpos()`。这两个函数是新由ANSI C引入的。它们引进了一个新的抽象数据类型`fpos_t`，它记录文件的位置。

- 需要移植到**非UNIX**系统上运行的应用程序应当使用`fgetpos()`和`fsetpos()`

## 【2】获取文件位置 `ftell`

### （1）函数原型

```c
long ftell(FILE *stream);
```

### （2）函数功能

- 获取文件的位置

### （3）函数参数

- stream : 要操作的文件指针

### （4）函数返回值

- 成功返回:  文件的位置

- 失败返回 :

  - 错误时返回 -1 , 并设置errno

  - Otherwise, -1 is returned and errno is set to indicate the error.

### （5）`fopen`打开文件的方式

- “r” ： 文件位置在开头。

- “w” ： 文件位置在开头。

- “a” ： 每次写入都追加到文件末尾；不要依赖追加模式的初始位置计算文件大小，应显式 `fseek` 到末尾。

### （6）练习-`ftell`计算文件大小

使用`ftell`计算文件的大小

```c
#include <stdio.h>

int main(int argc, char const *argv[])
{
    // 使用 ftell 计算当前文件大小
    if (argc != 2)
    {
        printf("Usage: %s filename\n", argv[0]);
        return -1;
    }

    // 以只读二进制模式打开，避免创建文件或修改内容
    FILE *fp = fopen(argv[1], "rb");
    if (fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    // 适用于可定位的普通文件，管道等流不支持 SEEK_END
    if (fseek(fp, 0, SEEK_END) != 0)
    {
        perror("fseek");
        fclose(fp);
        return -1;
    }
    long file_size = ftell(fp);
    if (file_size == -1L)
    {
        perror("ftell");
        fclose(fp);
        return -1;
    }
    // 关闭文件
    fclose(fp);

    printf("文件大小: %ld 字节\n", file_size);

    return 0;
}
```

## 【3】设置文件的位置 `fseek`

### （1）函数原型

```c
int fseek(FILE *stream, long offset, int whence);
```

### （2）函数功能

- 设置文件的位置

### （3）函数参数

- stream : 要操作的文件指针

- offset : 基于 whence  的偏移量, 以字节计算偏移量

- whence

  - SEEK\_SET  : 设置文件指定的位置

  - SEEK\_CUR : 基于当前的文件位置

  - SEEK\_END : 基于文件末尾的位置

### （4）函数返回值

- 成功返回:  0

- 失败返回 :

  - 错误时返回 -1 , 并设置errno

  - Otherwise, -1 is returned and errno is set to indicate the error.

### （5）常用用法

```c
// 1. 把文件位置设置到开始
fseek(fp,0,SEEK_SET);

// 2. 把文件位置设置到末尾
fseek(fp,0,SEEK_END );

// 3. 把文件位置设置到末尾的前一个元素
fseek(fp,-1,SEEK_END );

// 4. 基于文件位置的前1个元素
fseek(fp,-1,SEEK_CUR  );

// 5. 基于文件位置的后1个元素
fseek(fp,1,SEEK_CUR  );
```

### （6）练习-`fseek`合并文件

```c
#include <stdio.h>
#include <string.h>

int main(int argc, char const *argv[])
{
    // 使用 fseek 将两个文件合为一个文件 需要 第一个源文件 第二个源文件 目标文件
    if (argc != 4)

    {
        printf("source and target must be different\n");
        return -1;
    }

    // 打开源文件1
    FILE *fp_src_one = fopen(argv[1], "rb");

    {
        perror(argv[1]);
        return -1;
    }

    // 打开源文件2
    FILE *fp_src_two = fopen(argv[2], "rb");
    if (fp_src_two == NULL)
    {
        perror(argv[2]);
        fclose(fp_src_one);
        return -1;
    }

    // 打开目标文件
    FILE *fp_target = fopen(argv[3], "wb");
    if (fp_target == NULL)
    {
        perror(argv[3]);
        // 打开目标文件出错 关闭 打开的文件
        fclose(fp_src_one);
        fclose(fp_src_two);
        return -1;
    }

    // 记录第一个文件的大小
    int ret = 0;
    // 记录第一个文件的大小
    long size1 = 0;

    // 读取源文件1 写入目标文件
    // 使用 fgetc + fputc 写入目标文件
    int ch;
    while ((ch = fgetc(fp_src_one)) != EOF)
    {
        fputc(ch, fp_target);
    }

    // 输出第一个文件的大小和目标文件的大小
    // ftell 会考虑标准 I/O 缓冲；fflush 用于主动提交缓冲数据，并非获取位置的前提
    if (ret == 0)
    {
        fflush(fp_target);
        size1 = ftell(fp_target);
        printf("第一个文件大小: %ld 字节\n", size1);
    }

    // 读取源文件2 写入目标文件
    // 使用 fread + fwrite 写入目标文件
    char buf[1024] = {0};
    size_t read_size = 0;
    while ((read_size = fread(buf, 1, sizeof(buf), fp_src_two)) != 0)
    {
        fwrite(buf, 1, read_size, fp_target);
    }

    // 输出第二个文件的大小和目标文件的大小
    // 第二个文件大小 = 总大小 - 第一个文件大小
    if (ret == 0)
    {
        fflush(fp_target);
        long total = ftell(fp_target);
        printf("第二个文件大小: %ld 字节\n", total - size1);
        printf("目标文件大小: %ld 字节\n", total);
    }

    // 关闭文件
    fclose(fp_src_one);
    fclose(fp_src_two);
    fclose(fp_target);

    return 0;
}
```

### （7）练习-`fseek`拆分文件

把1个文件从中间拆分成2个文件

```c
#include <stdio.h>
#include <string.h>

int main(int argc, char const *argv[])
{
    // 使用 fseek 将一个文件从中间拆分为两个文件 需要一个源文件
    if (argc != 2)
    {
        printf("Usage: %s source\n", argv[0]);
        return -1;
    }

    // 打开源文件
    FILE *fp_src = fopen(argv[1], "rb");
    if (fp_src == NULL)
    {
        perror(argv[1]);
        return -1;
    }

    // 定位到文件末尾并检查结果；普通文件之外的流可能不可定位
    if (fseek(fp_src, 0, SEEK_END) != 0)
    {
        perror("fseek");
        fclose(fp_src);
        return -1;
    }
    long file_size = ftell(fp_src);
    if (file_size == -1L)
    {
        perror("ftell");
        fclose(fp_src);
        return -1;
    }
    // 移到文件开头
    fseek(fp_src, 0, SEEK_SET);

    // 从中间拆开：前一半 file_size / 2，后一半 file_size - file_size / 2
    long half = file_size / 2;
    long rest = file_size - half;

    // 提取文件名的主干和扩展名
    char base_name[512] = {0};
    char ext_name[512] = {0};
    char *dot = strrchr(argv[1], '.');
    char *slash = strrchr(argv[1], '/'); // 防止把类似 ./dir/name 里的点当成扩展名

    if (dot != NULL && (slash == NULL || dot > slash))
    {
        // 有扩展名，如 dst.c -> base_name: dst, ext_name: .c
        size_t base_length = (size_t)(dot - argv[1]);
        if (base_length >= sizeof(base_name) || strlen(dot) >= sizeof(ext_name))
        {
            fprintf(stderr, "文件名过长\n");
            fclose(fp_src);
            return -1;
        }
        memcpy(base_name, argv[1], base_length);
        base_name[base_length] = '\0';
        snprintf(ext_name, sizeof(ext_name), "%s", dot);
    }
    else
    {
        // 没有扩展名，直接全当主名
        if (strlen(argv[1]) >= sizeof(base_name))
        {
            fprintf(stderr, "文件名过长\n");
            fclose(fp_src);
            return -1;
        }
        snprintf(base_name, sizeof(base_name), "%s", argv[1]);
    }

    // 两个目标文件名的构成 以 源文件名-1 和 源文件名-2 命名
    char name_one[4096] = {0};
    char name_two[4096] = {0};
    snprintf(name_one, sizeof(name_one), "%s-1%s", base_name, ext_name);
    snprintf(name_two, sizeof(name_two), "%s-2%s", base_name, ext_name);

    // 打开目标文件1
    FILE *fp_one = fopen(name_one, "wb");
    if (fp_one == NULL)
    {
        perror("fopen");
        fclose(fp_src);
        return -1;
    }

    // 打开目标文件2
    FILE *fp_two = fopen(name_two, "wb");
    if (fp_two == NULL)
    {
        perror("fopen");
        fclose(fp_src);
        fclose(fp_one);
        return -1;
    }

    // 读取源文件前一半 写入目标文件1
    // 使用 fread + fwrite，每次最多读 1024 字节，读完 half 字节为止
    char buf[1024] = {0};
    size_t read_size = 0;
    long done = 0;
    while (done < half)
    {
        // 最后一次可能不够 1024，只读到 half 为止
        size_t want = sizeof(buf);
        if (half - done < (long)want)
        {
            want = (size_t)(half - done);
        }
        read_size = fread(buf, 1, want, fp_src);
        if (read_size != want)
        {
            perror("fread");
            fclose(fp_src);
            fclose(fp_one);
            fclose(fp_two);
            return -1;
        }
        fwrite(buf, 1, read_size, fp_one);
        done += (long)read_size;
    }

    // 输出第一个文件的大小
    printf("第一个文件大小: %ld 字节\n", half);

    // 读取源文件后一半 写入目标文件2
    done = 0;
    while (done < rest)
    {
        size_t want = sizeof(buf);
        if (rest - done < (long)want)
        {
            want = (size_t)(rest - done);
        }
        read_size = fread(buf, 1, want, fp_src);
        if (read_size != want)
        {
            perror("fread");
            fclose(fp_src);
            fclose(fp_one);
            fclose(fp_two);
            return -1;
        }
        fwrite(buf, 1, read_size, fp_two);
        done += (long)read_size;
    }

    // 输出第二个文件的大小和目标文件的总大小
    printf("第二个文件大小: %ld 字节\n", rest);
    printf("源文件总大小: %ld 字节\n", file_size);

    // 关闭文件
    fclose(fp_src);
    fclose(fp_one);
    fclose(fp_two);

    return 0;
}
```

### （8）练习-`fseek`文件逆序

```c
        base_name[base_length] = '\0';

    }
    else
    {
        // 没有扩展名，直接全当主名
        if (strlen(argv[1]) >= sizeof(base_name))
        {
            fprintf(stderr, "文件名过长\n");
            fclose(fp_src);
            return -1;
        }
        snprintf(base_name, sizeof(base_name), "%s", argv[1]);
    }

    // 目标文件名的构成 以 源文件名-rev.扩展名 命名
    char name_dst[1024] = {0};
    int name_length = snprintf(name_dst, sizeof(name_dst), "%s-rev%s", base_name, ext_name);
    if (name_length < 0 || (size_t)name_length >= sizeof(name_dst))
    {
        printf("错误：生成的目标文件名过长\n");
        fclose(fp_src);
        return -1;
    }

    // 打开目标文件
    FILE *fp_dst = fopen(name_dst, "wb");
    if (fp_dst == NULL)
    {
        perror(name_dst);
        fclose(fp_src);
        return -1;
    }

    char buf[1024] = {0};

        {
            perror("fseek");
            fclose(fp_src);
            fclose(fp_dst);
            return -1;
        }

        // 读取数据
        read_size = fread(buf, 1, want, fp_src);
        if (read_size != want)
        {
            perror("fread");
            fclose(fp_src);
            fclose(fp_dst);
            return -1;
        }

        // 将这一块数据在内存中倒序
        for (size_t i = 0; i < read_size / 2; i++)
        {
            char temp = buf[i];
            buf[i] = buf[read_size - 1 - i];
            buf[read_size - 1 - i] = temp;
        }

        // 写入目标文件
        fwrite(buf, 1, read_size, fp_dst);

        // 更新剩余未读字节数
        remain = offset;
    }

    printf("文件反转完成！\n");
    printf("源文件大小: %ld 字节\n", file_size);
    printf("目标文件: %s\n", name_dst);

    // 关闭文件
    fclose(fp_src);
    fclose(fp_dst);

    return 0;
}
```

# 【补充】验证与排查

- 将完整练习代码单独保存为 `stdio-demo.c`，用 `gcc -std=c11 -Wall -Wextra stdio-demo.c -o stdio-demo` 编译，再按该练习的参数运行。`FILE` 内部结构片段和标为错误用法的代码仅用于讲解。
- 复制练习应使用空文件、普通文本、超过 1024 字节的文件和含 `0x00` / `0xFF` 的二进制文件验证；用 `cmp source target` 检查内容是否一致。`fgets` / `fputs` 版本仅作为文本练习。
- 拆分后用 `cat part1 part2 > restored` 合并，再用 `cmp source restored` 检查；逆序示例按字节反转，不能用于保持 UTF-8 汉字完整性。
- 读取返回短计数时检查 `ferror` 与 `feof`；写入要检查 `fwrite` 的返回计数，关闭输出流也应检查 `fclose`，以发现缓冲刷新时才出现的错误。本文练习侧重 API 基本用法，并未逐一覆盖所有失败路径。
- `Too many open files`：用 `ulimit -n` 查看当前限制，确认是否遗漏 `fclose`。`Illegal seek`：检查输入是否为管道等不可定位的流。大文件定位还要考虑 `long` 的范围，Linux 下可结合 `fseeko` / `ftello` 与大文件支持。
