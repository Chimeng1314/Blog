# 【一】Linux时间介绍

Linux 时钟分为系统时钟（System Clock）和硬件（Real Time Clock，简称 RTC）时钟。

在Linux中有硬件时钟与系统时钟等两种时钟。硬件时钟是指主机板上的时钟设备，也就是通常可在BIOS画面设定的时钟。系统时钟则是指kernel中的时钟。

当Linux启动时，系统时钟会去读取硬件时钟的设定，之后系统时钟即独立运作。所有Linux相关指令与函数都是读取系统时钟的设定。

多数用户态命令和程序读取系统时钟。常用查看/设置工具包括 `date`、`hwclock` 和 `timedatectl`；`clock` 是一些系统中保留的旧命令或 `hwclock` 的兼容名称。

# 【二】Linux时间设置命令

## 【1】date 显示与设置时间命令

`date` 用于显示或设置系统日期与时间。手动修改时间会影响日志、TLS 证书、构建系统和网络服务；生产环境通常应使用 NTP 同步而非频繁手工设置。

运维人员可以根据想要的格式来输出系统时间信息，时间格 MMDDhhmm[CC][YY][.ss] ，其中 MM 为月份，DD 为日，hh 为小时，mm 为分钟，CC 为年份前两位数字，YY 为年份后两位数字，ss 为秒数。

语法格式：date [选项] [+输出形式]

常用参数：

- `-d <字符串>`：按给定字符串解析并显示时间，不修改系统时间。
- `-s <字符串>`：设置系统时间，需要管理员权限。
- `-u`：以 UTC 显示或设置时间。
- `+<格式>`：自定义输出格式，例如 `+%F`、`+%T`。

参考实例

```bash
linux@ubuntu:~$ date
2022年 08月 26日 星期五 15:41:15 CST
linux@ubuntu:~$ date "+%Y-%m-%d"
2022-08-26
linux@ubuntu:~$ date "+%Y-%m-%d %H:%M:%S"
2022-08-26 15:43:11
linux@ubuntu:~$ sudo date -s "2022-08-27 18:10:30"
[sudo] linux 的密码：
2022年 08月 27日 星期六 18:10:30 CST
linux@ubuntu:~$ date
2022年 08月 27日 星期六 18:10:31 CST
```

若启用了自动时间同步，服务可能随后校正手工设置的时间。可先用 `timedatectl status` 检查同步状态；排障时临时关闭同步后，完成操作应及时恢复。

## 【2】hwclock命令

hwclock命令是一个硬件时钟访问工具，它可以显示当前硬件时间、设置硬件时钟的时间和设置硬件时钟为系统时间，也可设置系统时间为硬件时钟的时间。

语法格式：hwclock [参数]

常用参数：
--debug
显示hwclock执行时详细的信息。
--directisa
hwclock预设从/dev/rtc设备来存取硬件时钟。若无法存取时，可用此参数直接以I/O指令来存取硬件时
钟。
--hctosys
将系统时钟调整为与目前的硬件时钟一致。
--set --date="日期与时间"
设定硬件时钟。

--show
显示硬件时钟的时间与日期。
--systohc
将硬件时钟调整为与目前的系统时钟一致。
--test
仅测试程序，而不会实际更改硬件时钟。
--utc
若要使用格林威治时间，请加入此参数，hwclock会执行转换的工作。
--version
显示版本信息。

参考实例

```bash
linux@ubuntu:~$ sudo hwclock    # 查看硬件时间
2023-08-10 12:00:07.760036+0800
linux@ubuntu:~$ sudo hwclock --hctosys   # 把硬件时钟写入系统时钟
linux@ubuntu:~$ date
2023年 08月 10日 星期四 12:00:08 CST
linux@ubuntu:~$ sudo hwclock
2022-08-26 16:02:40.743598+0800
linux@ubuntu:~$ sudo hwclock --set --date="2023-08-10 12:00:00"   # 关闭网络和自动校正时间选项 , 并设置时间
linux@ubuntu:~$ sudo hwclock
2023-08-10 12:00:05.009811+0800
linux@ubuntu:~$ sudo hwclock --hctosys  # hwclock to system：硬件时间同步到系统时间
linux@ubuntu:~$ date                    # 系统时间改变
2023年 08月 10日 星期四 12:00:19 CST
linux@ubuntu:~$ sudo date -s "2022-08-27 18:10:30"  #需要使用sudo
[sudo] linux 的密码：
2022年 08月 27日 星期六 18:10:30 CST
linux@ubuntu:~$ sudo hwclock
2023-08-10 12:01:11.103429+0800
linux@ubuntu:~$ sudo hwclock --systohc    # system to  hwclock 把系统时间同步到硬件时间内
linux@ubuntu:~$ sudo hwclock
2022-08-27 18:11:01.400677+0800
```

## 【3】tzselect时区的设置命令

tzselect ： time zone select

`tzselect` 会交互式推荐一个 `TZ` 值，但**不会直接修改系统时区**。它适合查询；在使用 systemd 的发行版上，设置系统时区优先使用 `timedatectl set-timezone`。

语法格式：tzselect [参数]

常用参数：
-c COORD
根据自定义数值设置时区
-n LIMIT
当使用-c时，显示大多数LIMIT位置（默认为10）

## 【4】NTP 时间同步与 `ntpdate` 命令

`ntpdate` 可向 NTP 服务器查询并一次性校正本地时间，但在许多发行版中已不再是推荐的长期同步方案。日常同步应使用 `systemd-timesyncd`、chrony 或发行版提供的 NTP 服务，避免多个同步服务同时修改时钟。

长期同步服务会持续选择时间源并平滑校正时钟。应优先使用组织或发行版配置的可信 NTP 源，不要随意依赖来历不明的公网服务器。

语法格式：ntpdate [参数]

常用参数：
-aKeyid
使用 Keyid 来认证全部数据包
-b
通过调用 settimeofday 子例程来增加时钟的时间

先检查并启用系统的自动时间同步：

```bash
timedatectl status
sudo timedatectl set-ntp true
```

以下为仅在需要一次性校时、且确认系统没有其他时间同步服务竞争时使用的 `ntpdate` 示例：

```bash
linux@ubuntu:~$ ntpdate
找不到命令 “ntpdate”，但可以通过以下软件包安装它：
sudo apt install ntpdate         # version 1:4.2.8p15+dfsg-1ubuntu2, or
sudo apt install ntpsec-ntpdate  # version 1.2.1+dfsg1-4
linux@ubuntu:~$ sudo apt install ntpdate # 安装 ntpdate 工具包

linux@ubuntu:~$ sudo ntpdate ntp.tencent.com
24 Sep 20:09:15 ntpdate[5685]: step time server 106.55.184.199 offset -31598117.776736 sec
linux@ubuntu:~$ date
2024年 09月 24日 星期二 20:10:15 CST
linux@ubuntu:~$ sudo date -s "2023-10-01 12:00:00"
2023年 10月 01日 星期日 12:00:00 CST
linux@ubuntu:~$ date
2023年 10月 01日 星期日 12:00:01 CST
linux@ubuntu:~$ sudo ntpdate  ntp.tencent.com
24 Sep 20:10:56 ntpdate[5751]: step time server 106.55.184.199 offset +31047042.458986 sec
linux@ubuntu:~$ date
2024年 09月 24日 星期二 20:10:58 CST
```

# 【补充】验证与故障排查

用 `timedatectl status` 核对时区、系统时间与同步状态。自动同步开启时不要同时运行多套校时服务；时间仍漂移时检查所用 NTP 服务日志、网络连通性及虚拟机宿主时间。
