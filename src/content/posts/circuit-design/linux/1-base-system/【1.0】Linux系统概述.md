# 【一】什么是 linux 系统

## 【1】什么是 Linux

Linux 的历史通常从 UNIX 谈起。1969 年，AT&T 贝尔实验室的 Ken Thompson 等人开始开发 UNIX；随后 Dennis Ritchie 参与开发，并在 1970 年代用 C 语言重写了主要部分。UNIX 的多用户、多任务设计及其工具思想，深刻影响了后来 Linux 的设计。

Unix 的版本主要两个：

AT&T System V —— 就是俗称的 “ 系统 5”

Berkeley Software Distribution (BSD) 。

## 【2】Linux 是一种操作系统

1991 年，芬兰赫尔辛基大学的学生 **Linus Torvalds** 因希望在个人电脑上获得更好的类 UNIX 使用环境，开始编写 Linux 内核。Linux 本身是内核；日常所说的“Linux 系统”通常是指 Linux 内核与 GNU 工具、桌面环境和应用软件组合而成的发行版。

1991.8.25 ，

Linus Torvalds 在 `comp.os.minix` 新闻组中发布了关于 Linux 项目的公开消息。随后，Linux 内核源码逐步以早期版本的形式公开。

由于人们的鼓励，继续编写可移植的 Linux 系统。

## 【3】Linux 的系统发展史

![什么是 linux 系统：Linux 的系统发展史（图 1）](https://oss.silentdream.top/2026/10/12/22-00-55-d65931e5-page-001-01-77af98.png)

### （1）第一阶段

1969 年，Ken Thompson 等人在贝尔实验室开发 UNIX 操作系统原型；其早期工作与在 PDP-7 上运行《星际旅行》（Space Travel）游戏有关。

1970 年代初，Dennis Ritchie 等人使用 C 语言重写 UNIX 的主要部分。良好的可移植性使 UNIX 在高校和研究机构中得到广泛传播。

总结：C 语言带来的可移植性，是 UNIX 得以广泛传播的重要原因。

### （2）第二阶段

1987 年，Andrew S. Tanenbaum 开发了用于教学的类 UNIX 系统 **MINIX**。它强调结构清晰、便于教学。

MINIX 可运行于当时常见的 x86 PC 平台，成为 Linus Torvalds 学习操作系统原理时接触的系统之一。

总结：MINIX 的主要目标是教学，而不是替代通用生产操作系统。

### （3）第三阶段

1990 年前后，芬兰赫尔辛基大学学生 Linus Torvalds 开始接触 MINIX 系统。

1991 年，Linus Torvalds 开始在 MINIX 环境中编写 Linux 内核的早期组件。

1991 年，Linux 的早期内核源码陆续公开，吸引了全球开发者参与改进。

1992 年，Linux 内核改用 GNU GPL 许可证发布；1994 年，Linux 1.0 正式发布。

1993 年，Slackware 等早期 Linux 发行版出现，降低了安装和使用 Linux 的门槛。

Linux 借鉴了 UNIX 的设计思想，因此通常被称为“类 UNIX（Unix-like）”系统；它并不是 UNIX 的直接代码分支。

# 【二】为什么要学习 linux 系统

学习 Linux 不应只因为“它是开源的”。更重要的是，Linux 在服务器、云计算、网络设备、嵌入式设备和开发环境中被广泛使用；学习它有助于理解操作系统、命令行工具链、网络与软件部署。

开源意味着源代码可被审阅、学习和再分发（具体权利受许可证约束），社区也提供了丰富的软件与文档。稳定性、可配置性和生态共同构成 Linux 的优势，但实际体验仍取决于所选发行版和具体配置。

在高性能计算领域，Linux 也长期是主流操作系统之一；许多超级计算机使用针对计算任务定制的 Linux 环境。

开源软件便具备了 4 大关键性优势。

- 低风险
  - 使用闭源软件无疑把命运交付给他人，一旦封闭的源代码没有人来维护，你将进退维谷。

- 低成本
  - 使用开源社区推动的软件项目可以节省大量的人力、物力和财力。

- 高品质
  - 开源项目可以被更多人审阅、测试和改进；但质量仍取决于维护活跃度、测试流程和发布策略，不能因此假定漏洞一定会被及时修复。

- 更透明
  - 源代码可审阅，便于社区和组织检查安全问题与异常改动；不过开源项目同样可能出现漏洞或供应链风险，仍应及时更新并遵循安全实践。

# 【三】开源精神及常见的 Linux 系统

一般情况下，软件的源代码只由编写者拥有，而开源（即开放源代码， Open Source Code ）是指一种更自由的软件发布模式。

用户通常可在许可证允许的范围内使用、复制、修改和再分发软件；不同许可证对署名、源码公开、商标和再发布方式的要求不同。

为了平衡两者的关系，截至目前，世界上已经有 100 多种被开源促进组织确认的开源许可证，用于保护开源工作者的权益。

## 【1】RedHat

红帽企业版 Linux 最初于 2002 年 3 月面世，是全世界使用最广泛的 Linux 系统之一，在世界 500 强企业中，所有的航空公司、电信服务提供商、商业银行、医疗保健公司均无一例外使用该系统。

RHEL 是面向企业的商业发行版，版本与支持周期会持续变化。它以长期维护、认证生态和商业技术支持为主要特点；使用时应以 Red Hat 官方生命周期页面为准。

## 【2】CentOS

CentOS 是由开源社区研发和维护的一款企业级 Linux 操作系统，在 2014 年 1 月被红帽公司正式收购。

传统 CentOS Linux 是基于 RHEL 源码构建的社区发行版。CentOS Linux 项目已结束维护；当前的 CentOS Stream 位于 Fedora 与 RHEL 之间，更适合希望跟踪 RHEL 后续版本变化的场景。

也正因为其免费的特性， CentOS 拥有了广泛的用户。

若需要长期稳定且免费兼容 RHEL 的环境，可根据实际需求评估 Rocky Linux、AlmaLinux 等社区发行版，并关注各自的支持策略。

## 【3】Fedora

Fedora 翻译为中文是 “ 浅顶软男帽 ” 的意思，翻译之后跟 Linux 系统很不搭界，所以更多人干脆将其音译为 “ 费多拉 ” 系统。

Fedora 是由社区与 Red Hat 支持的发行版，通常较早提供新技术，适合桌面开发、学习和体验。它的发布节奏较快，单个版本支持期相对较短。

## 【4】Debian

Debian 是一个社区驱动的 Linux 发行版，最初发布于 1993 年。其名称由创始人 Ian Murdock 与 Debra 的名字组合而来。Debian 遵循《Debian 自由软件指导方针》（DFSG），软件包可采用多种开源许可证，并非全部使用 GNU GPL。

Debian 被翻译为 “ 蝶变 ” 系统。但可惜国内的用户不多。
Debian 系统具有很强的稳定性和安全性，并且提供了免费的基础支持，可以良好地适应各种硬件架构，以及提供近十万种不同的开源软
件，在国外拥有很高的认可度和使用率。

## 【5】Ubuntu

Ubuntu 是基于 Debian 的 Linux 发行版，提供桌面版和服务器版。通常每 6 个月发布一个常规版本，并定期发布长期支持版（LTS）。

Ubuntu 的中文音译为 “ 乌班图 ” ，这个词最初来自于非洲南部部落使用的祖鲁语，意思是 “ 我的存在是因为大家的存在 ” 。

Ubuntu 系统的第一个版本发布于 2004 年 10 月。 2005 年 7 月， Ubuntu 基金会成立， Ubuntu 后续不断增加开发分支，有了桌面版系统、服务器版系统。

尽管 Ubuntu 源自 Debian，但二者的软件仓库、版本节奏和默认配置不同，软件包并不保证完全兼容。

Ubuntu 因文档丰富、桌面体验完善，常被用于嵌入式开发的主机环境；实际目标设备则常使用 Buildroot、Yocto、OpenWrt 或厂商定制系统等方案。

## 【6】openSUSE Linux

一款源自德国的 Linux 系统，在全球范围内有着不错的声誉及市场占有率。

openSUSE 提供面向日常使用的 Leap 和滚动更新的 Tumbleweed 等分支，适合根据稳定性与软件新旧程度选择。

## 【7】Kali Linux

Kali Linux 面向经授权的安全测试、数字取证与安全研究，预装了大量相关工具。未经授权扫描、测试或攻击他人的系统可能违法。

Kali Linux 系统的前身名为 BackTrack ，其设计用途就是进行数字鉴识和渗透测试，内置有 600 多款网站及系统的渗透测试软件，包括大名鼎鼎的 Nmap 、 Wireshark 、 sqlmap 等。

## 【8】深度操作系统（ deepin ）

在过去的十多年，基于开源系统二次定制开发的 “ 国产操作系统 ” 陆续出现过一些，但大多发展不好，深度操作系统却是少数能够将技术研发与商业运作结合起来的成功案例。

# 【四】Ubuntu 系统介绍

## 【1】ubuntu 的由来

Ubuntu Linux 是由南非人马克 · 沙特尔沃思 (Mark Shuttleworth) 创办的基于 Debian Linux 的操作系统，于 2004 年 10 月公布 Ubuntu 的第一个版本 (Ubuntu 4.10“Warty Warthog”) 。

Ubuntu 适用于笔记本电脑、桌面电脑和服务器，特别是为桌面用户提供尽善尽美的使用体验。

Ubuntu 提供了一个健壮、功能丰富的计算环境，既适合家庭使用又适用于商业环境。 Ubuntu 社区承诺每 6 个月发布一个新版本，以提供最新最强大的软件。

## 【2】ubuntu 的特点

Ubuntu 的具体预装软件会随版本、安装选项和桌面环境变化，但通常具有以下特点：

1. 提供面向桌面与服务器的安装镜像，并拥有较完整的硬件与软件生态。
2. 支持图形化系统设置，也可通过命令行完成网络、软件包和服务管理。
3. 可通过软件仓库安装开发工具、多媒体工具和办公软件；是否预装取决于版本与安装方式。
4. 提供语言、无障碍、蓝牙、打印和电源管理等常用桌面功能；硬件支持情况应以实际设备和驱动为准。
5. LTS 版本适合追求较长维护周期的学习和开发环境，常规版本则更快引入新软件版本。

# 【补充】验证与故障排查

运行 `uname -r` 查看内核版本，`cat /etc/os-release` 查看发行版；两者不是同一个版本号。选择发行版时再核对官方支持周期。
