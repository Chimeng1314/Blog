# 【一】Shell 的理解

随着各式 Linux 系统的图形化程度的不断提高，用户在桌面环境下，通过点击、拖拽等操作就可以完成大部分的工作。

然而，许多 Ubuntu Linux 功能使用 Shell 命令来实现，要比使用图形界面交互，完成的更快、更直接。

英文单词 Shell 可直译为 “ 贝壳 ” 。 “ 贝壳 ” 是动物作为外在保护的一种工具。

可以这样认为， Linux 中的 Shell 就是 Linux 内核的一个外层保护工具，并负责完成用户与内核之间的交互。

![Shell 的理解（图 1）](https://oss.silentdream.top/2026/10/12/22-00-55-67906040-page-020-01-60d2cb.png)

命令是用户向系统内核发出控制请求，与之交互的文本流。

Shell 是一个命令行解释器，将用户命令解析为操作系统所能理解的指令，实现用户与操作系统的交互。

同时， Shell 为操作系统提供了内核之上的功能，直接用来管理和运行系统。

当需要重复执行若干命令，可以将这些命令集合起来，加入一定的控制语句，编辑成为 Shell 脚本文件，交给 Shell 批量执行。

# 【九】Shell 查询命令历史

history 命令用于显示执行过的命令历史，语法格式为 “history [-c]” 。

`history` 命令用于查看当前 Shell 保存的历史记录。显示数量受 `HISTSIZE`、`HISTFILESIZE` 和 Shell 配置影响，并不固定为 1000 条。

如果觉得1000 不够用，可以自定义 /etc/profile 文件中的 HISTSIZE 变量值。

`history -c` 清空当前 Shell 内存中的历史记录；是否写回历史文件及其他终端是否仍保留记录，取决于 Shell 的历史配置。清理前应确认不会丢失排障或审计所需信息。

还可以使用 “! 编码数字 ” 的方式来重复执行某一次的命令。

```bash
    8  ls
    9  shell
   10  ls
   11  sudo su
   12  pwd

linux@ubuntu:~$ !1    # 执行命令历史的第一个命令

    1  history
```

## 【1】通配符

当需要用命令处理一组文件，例如file1.txt、file2.txt、file3.txt……，用户不必一一输入文件名，可以使用Shell通配符。

1. **星号（`*`）**：匹配任意长度的字符串。用 `file_*.txt`，匹配 `file_wang.txt`、`file_zhang.txt`、`file_liu.txt`
2. **问号（`?`）**：匹配一个长度的字符。用 `file_?.txt`，匹配 `file_1.txt`、`file_2.txt`、`file_3.txt`
3. **方括号（`[...]`）**：匹配其中指定的一个字符。用 `file_[otr].txt`，匹配 `file_o.txt`、`file_r.txt`和`file_t.txt`
4. **方括号（`[-]`）**：匹配指定的一个字符范围。用 `file_[a-z].txt`，匹配 `file_a.txt`、`file_b.txt`，直到 `file_z.txt`
5. **方括号（`[!...]`）**：匹配不在集合中的一个字符。Bash 也支持 `[^...]`，但 `[!...]` 更符合 glob 的常见写法。`file_[!otr].txt` 可匹配除 `file_o.txt`、`file_r.txt`、`file_t.txt` 之外的单字符文件名；它与 C 语言 `scanf` 的扫描集语法不是同一规则。

* 操作结果

# 【十二】Shell 命令置换

命令替换是将一个命令的输出作为另一个命令的参数。命令格式如下所示。

```bash
command1 "$(command2)" # $(...) 是推荐的命令替换写法
```

其中，命令 command2 的输出将作为命令 command1 的参数。需要

## 【1】`ls` 命令

## 【2】 `cd` 命令

### （1）作用
`cd` 用于切换当前工作路径，英文全称是 **change directory**。


## 【8】`rm` 命令

### （1）作用
删除文件或目录，英文全称是 **remove**。它是 `rmdir` 的替代方案，更常用。

`rm` 默认不会逐个询问；是否提示还会受别名（例如 `alias rm='rm -i'`）和终端环境影响。`-f` 会忽略不存在文件并禁止提示，应谨慎使用。

要想删除一个目录，需要在`rm`命令后面加一个`-r`参数才可以，否则删除不掉。

### （2）语法
```bash
rm [参数] 文件名称
```

### （3）常用参数
| 参数 | 作用             |
| ---- | ---------------- |
| `-f` | 强制执行，不提示 |
| `-i` | 删除前询问       |
| `-r` | 递归删除目录     |
| `-v` | 显示删除过程     |

### （4）示例与输出
```bash
linux@ubuntu:~/work$ ls
1.c 2.c 3.c 4.c 5.c 6.c 7.c 8.c dir2 dir3 dir4

linux@ubuntu:~/work$ rm 1.c

linux@ubuntu:~/work$ rm dir2/
rm: 无法删除'dir2/': 是一个目录

linux@ubuntu:~/work$ rm -r dir2/

linux@ubuntu:~/work$ rm -rf dir3 1.c 4.c

linux@ubuntu:~/work$ ls
2.c 3.c 5.c 6.c 7.c 8.c dir4
```

说明：
```bash
rm file1          # 删除 file1 文件
rm -r dir1        # 删除目录 dir1
rm -rf 文件或目录  # 强制删除，不报错误提示
```

注意：`rm -rf` 会递归且强制删除，通常无法从命令行直接恢复。执行前建议先用 `pwd`、`ls -- <目标>` 核对位置和目标；含通配符或变量时更应谨慎，避免以 `/`、`~` 等宽泛路径为目标。

## 【11】`man` 命令

### （1）作用
man是系统的手册分页程序。指定给man的页选项通常是程序、工具或函数名。

程序将显示每一个找到的相关手册页。如果指定了章节，man将只在手册的指定章节搜索。

默认将按预定的顺序查找所有可用的 章节 (默认是“1 n 1 8 3 2 3posix 3pm 3per1 3am 5 4 9 6 7”),并只显示找到的第一个页，即使多个章节中都有这个页面。

### （2）语法
```bash
man 命令/函数名
```

man 命令的退出使用 q 退出

### （3）手册章节

| 章节号 | 内容                                          |
| ------ | --------------------------------------------- |
| 1      | 可执行程序或 shell 命令                       |
| 2      | 系统调用，内核提供的函数                      |
| 3      | 库调用，程序库中的函数                        |
| 4      | 特殊文件，通常位于 `/dev`                     |
| 5      | 文件格式和规范，如 `/etc/passwd`              |
| 6      | 游戏                                          |
| 7      | 杂项，包括宏包和规范，如 `man(7)`、`groff(7)` |
| 8      | 系统管理命令，通常只针对 root 用户            |
| 9      | 内核例程，非标准                              |

### （4）示例
```bash
man 1s     #查找1s命令的帮助
man rmdir  #查找rmdir 命令的帮助
man 1 read #在第1章(可执行程序)中去查找read 命令
man 2 read #在第2章(可执行程序)中去查找read 命令
man man    #给出man命令本省的帮助
```

说明：默认按预定顺序查找所有可用章节，并只显示找到的第一个页面。

```bash
linux@ubuntu:~/work$ man 1 stat    # 在第1章中去查找stat
linux@ubuntu:~/work$ man 2 stat    # 在第2章中去查找stat
```

```bash

```
