# 【一】文件系统分类

Linux系统中颇具特色的文件存储结构常常搞得新手头昏脑涨，本章将从Linux系统中的文件存储结构开始，讲述文件系统层次标准
（Filesystem Hierarchy Standard，FHS）、udev硬件命名规则以及硬盘设备的原理。

Linux系统支持数十多种文件系统，而最常见的文件系统如下所示。

Ext2：1993 年引入的文件系统，不提供日志功能。异常关机后可能需要较长的一致性检查；是否适用取决于设备和可靠性需求。

Ext3：在 Ext2 基础上加入日志。常见的 ordered 模式主要记录元数据，并非记录所有文件内容；日志有助于崩溃恢复，但不能保证所有未落盘数据不丢失，也不能代替备份。

Ext4：Ext3 的后继者，也是许多 Linux 发行版的常用文件系统。它支持 extent、延迟分配和多块分配等特性。容量、文件大小与目录数量的上限取决于块大小、特性开关及实现版本，不能理解为无限；详细限制见内核文档。

# 【二】文件系统的根(/)

在Linux系统中，目录、字符设备、套接字、硬盘、光驱、打印机等都被抽象成文件形式，一直强调的“Linux系统中一切都是文件”。

既然平时我们打交道的都是文件，那么又应该如何找到它们呢？在Windows操作系统中，想要找到一个文件，要依次进入该文件所在的磁盘分区（也叫盘符），然后再进入该分区下的具体目录，最终找到这个文件。

但是在Linux系统中并不存在C、D、E、F等盘符，Linux系统中的一切文件都是从“根”目录（/）开始的，并按照文件系统层次标准（FHS）
采用倒树状结构来存放文件，以及定义了常见目录的用途。

另外，Linux系统中的文件和目录名称是严格区分大小写的。

例如，root、rOOt、Root、rooT均代表不同的目录，并且文件名称中不得包含斜杠（/）。

# 【三】物理设备命名规则

在Linux系统中一切都是文件，硬件设备也不例外。

既然是文件，就必须有文件名称。运行在用户空间、接收内核设备事件的 udev 设备管理器会自动把硬件名称规范起来，目的是让用户通过设备文件的名字可以猜出设备大致的属性以及分区信息等。

Linux系统中常见的硬件设备及其文件名称如图所示。

![物理设备命名规则（图 1）](https://oss.silentdream.top/2026/10/12/22-00-55-a1c2ea77-page-046-02-3f9250.png)

IDE : 老式的硬盘

SATA :目前流行的硬盘

第一个知识点是设备名称的理解错误。比如/dev/sda表示主板上第一个插槽上的存储设备，读者在实践操作的时候会发现果然如此，因此也就对这条理论知识更加深信不疑。

但真相不是这样的，/dev目录中sda设备之所以是a，并不是由插槽决定的，而是由系统内核的识别顺序来决定的，而恰巧很多主板的插槽顺序就是系统内核的识别顺序，因此才会被命名为/dev/sda。

大家以后在使用SCSI网络存储设备时就会发现，明明主板上第二个插槽是空着的，但系统却能识别到/dev/sdb这个设备—就是这个道理。

第二个知识点是对分区名称的理解错误。

分区的编号代表分区的个数。比如sda3表示这是设备上的第3个分区，而学员在做实验的时候确实也会得出这样的结果。

但是这个理论知识是错误的，因为分区的数字编码不一定是强制顺延下来的，也有可能是手工指定的。因此sda3只能表示是编号为3的分区，而不能判断sda设备上已经存在了3个分区。

![物理设备命名规则（图 2）](https://oss.silentdream.top/2026/10/12/22-00-55-19b7fb65-page-047-01-0bc96e.png)

首先，/dev/目录中保存的应当是硬件设备文件；

其次，sd表示的是存储设备；

然后，a表示系统中同类接口中第一个被识别到的设备；

最后，5表示这个设备是一个逻辑分区。

`/dev/sda5` 是内核为某个磁盘分区分配的设备节点。传统 MBR 的扩展分区场景中，编号 5 及以上常为逻辑分区；GPT 不区分主分区、扩展分区和逻辑分区。设备枚举顺序可能变化，脚本和 `/etc/fstab` 中优先使用 `UUID=`、`LABEL=` 或 `/dev/disk/by-id/`。

# 【四】fdisk 分区磁盘

`fdisk` 用于查看、创建和维护分区表，支持常见的 MBR（DOS）与 GPT 分区表。写入分区表会改变磁盘元数据，操作前必须确认目标磁盘不是系统盘或正在使用的业务盘。

建议先使用以下只读命令核对磁盘、分区、文件系统和挂载点：

```bash
lsblk -o NAME,SIZE,TYPE,FSTYPE,UUID,MOUNTPOINTS
sudo fdisk -l
```

查看磁盘信息命令格式: `fdisk -l [device...]`

对磁盘进行分区操作：`sudo fdisk /dev/<磁盘>`。`w` 写入后才会生效；`q` 不保存退出。不要把示例中的 `/dev/sdb` 直接套用到其他机器。

# 【五】`mkfs` 格式化分区

`mkfs`（make file system）用于在**分区或设备**上创建文件系统，会覆盖该目标上原有的文件系统数据。通常应对分区（如 `/dev/sdb1`）而非整块磁盘操作；执行前再次使用 `lsblk -f` 核对目标。

在挂载使用硬盘空间前的最后一步，运维人员需要对整块硬盘或指定分区进行格式化文件系统操作，Linux系统支持的文件系统包含ext2、ext3、ext4、xfs、fat、msdos、vfat、minix等多种格式。

语法格式： mkfs [参数] 设备名

常用参数：
`-V` 详细显示模式
`-t` 给定档案系统的型式
`-c` 检查该设备是否有损坏

# 【六】mount 挂载与umount卸载设备

mount命令的功能是用于把文件系统挂载到目录，文件系统指的是被格式化过的硬盘或分区设备，进行挂载操作后，用户便可以在挂载目
录中使用硬盘资源了。

Ubuntu 桌面环境通常能自动挂载可移动介质；服务器和无桌面环境则常需手动挂载。先用 `lsblk -f` 查看设备及挂载点。

挂载设备语法格式：`mount [参数] <设备> <挂载点>`。挂载点应是已存在的目录，挂载后原目录中原有文件会被暂时遮蔽。

卸载设备语法格式：`umount <挂载点或设备>`。卸载前应离开该目录并关闭其中的文件；若提示 busy，可用 `lsof +f -- <挂载点>` 或 `fuser -vm <挂载点>` 排查占用，避免随意使用强制/延迟卸载。

挂载点：就是一个目录

参考实例

```bash
linux@ubuntu:~$ ls /mnt/
linux@ubuntu:~$ sudo mkdir /mnt/linux
linux@ubuntu:~$ ls /mnt/
linux

linux@ubuntu:~$ sudo mount /dev/sdb1  /mnt/linux/
linux@ubuntu:~$ ls /mnt/linux/
```

# 【七】`fatlabel`、`e2label` 修改卷标

`e2label` 用来设置 ext2/ext3/ext4 文件系统的卷标（label），卷标不是“盘符”。卷标可用于人类识别和挂载配置，但并非全局唯一。

`fatlabel` 命令用来设置 FAT 文件系统的卷标。修改前应先卸载对应文件系统；不同工具/文件系统对卷标长度和字符集限制不同。

ntfslabel 命令用来设置ntfs文件系统的卷标

实例

```bash

open: Permission denied

linux@ubuntu:~$ sudo fatlabel /dev/sdb1 HELLO
linux@ubuntu:~$ sudo e2label /dev/sdb2 kernel
linux@ubuntu:~$ sudo fatlabel /dev/sdb1 BOOT

linux@ubuntu:~$ sudo e2label /dev/sdb2
rootfs

BOOT
linux@ubuntu:~$ sudo e2label /dev/sdb1
```

# 【九】`du` 查看文件或目录的空间占用

du命令来自于英文词组“Disk Usage”的缩写，其功能是用于查看文件或目录的大小。

人们经常会把df和du命令混淆，df是用于查看磁盘或分区使用情况的命令，而du命令则是用于按照指定容量单位来查看文件或目录在磁盘中的占用情况。

语法格式：`du [参数] <文件或目录>`。`du -sh <目录>` 查看汇总大小；`du -xhd1 <目录>` 可在不跨文件系统的情况下按一级目录排查空间占用。

常用参数：﻿
`-a` 显示目录中所有文件大小
`-k` 以KB为单位显示文件大小
`-m` 以MB为单位显示文件大小
`-g`以GB为单位显示文件大小
`-h` 以易读方式显示文件大小
`-s` 仅显示总计
