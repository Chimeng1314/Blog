# 【一】用户与 UID

## 【1】管理员UID

**管理员UID为0**：系统的管理员用户。

## 【2】系统用户UID

系统用户的 UID 范围由发行版策略决定。以常见 Debian/Ubuntu 配置为例，普通用户通常从 1000 开始，较小的 UID 多预留给系统账户和服务账户。服务使用独立、低权限账户运行，有助于缩小服务被攻破后的影响范围。

## 【3】普通用户UID

**普通用户 UID 通常从 1000 开始**：用于日常登录和工作。实际范围可查看 `/etc/login.defs`，不要仅凭 UID 判断账户用途。

# 【二】`id` 命令

id命令用于显示用户的详细信息，语法格式为“id 用户名”。

`id` 可查看用户的 UID、主组 GID 和附加组；结合 `getent passwd <用户名>` 可用于确认账户是否存在。注意：用户名存在与否不应只依赖命令输出的本地文件，因为系统可能配置了 LDAP 等目录服务。

```bash
linux@ubuntu:~$ id linux
uid=1000(linux) gid=1000(linux) 组=1000(linux),
4(adm),24(cdrom),27(sudo),30(dip),46(plugdev),116(lpadmin),126(sambashare)
linux@ubuntu:~$ id root
uid=0(root) gid=0(root) 组=0(root)
linux@ubuntu:~$
```

# 【三】用户管理命令

`useradd` 与 `adduser`

在Ubuntu中创建新用户，通常会用到两个命令：`useradd`和`adduser`。虽然作用一样，但用法却不尽相同

## 【1】`useradd`创建用户

`useradd` 是较底层的账户创建工具，默认行为由 `/etc/default/useradd` 和 `/etc/login.defs` 决定。为得到可登录的普通用户，建议显式指定主目录和登录 Shell：

```bash
sudo useradd -m -s /bin/bash test
sudo passwd test
# -m：创建 /home/test；-s：指定登录 Shell；第二条命令设置密码
```

若不加参数，很多发行版不会自动创建主目录，账户密码也处于未设置或锁定状态；默认 Shell 是否可登录则取决于系统配置。创建后可用 `id test`、`getent passwd test` 核对结果。

## 【2】`adduser`创建用户

使用`adduser`时，创建用户的过程更像是一种人机对话，系统会提示你输入各种信息，然后会根据这些信息帮你创建新用户。

下面使用 `adduser` 创建名为 `dream` 的用户。示例中的姓名、电话等字段可直接按回车跳过，不要在终端记录真实密码或个人联系方式：

```bash
ubuntu@ubuntu:~$ sudo adduser dream
正在添加用户"dream"...
正在添加新组"dream" (1001)...
正在添加新用户"dream" (1001) 到组"dream"...
创建主目录"/home/dream"...
正在从"/etc/skel"复制文件...
新的密码：
无效的密码： 密码少于 8 个字符
重新输入新的密码：
passwd：已成功更新密码
正在改变 dream 的用户信息
请输入新值，或直接敲回车键以使用默认值
        全名 []:
        房间号码 []:
        工作电话 []:
        家庭电话 []:
        其它 []:
这些信息是否正确？ [Y/n] y
```

切换用户，验证是否创建成功

```bash
ubuntu@ubuntu:~$ su - dream
密码：
dream@ubuntu:~$
```

## 【3】`userdel `删除用户

`userdel`命令用于删除已有的用户账户，英文全称为`user delete`，语法格式为`userdel [参数] 用户名`。

删除账户前先确认该账户没有正在运行的重要任务，并备份需要保留的数据。`userdel` 默认保留家目录；`-r` 会一并删除家目录和邮件假脱机文件，属于不可逆操作。

`userdel`命令的参数以及作用如表所示。

```bash
# 先查看该账户的会话与进程；确认可终止后再继续
loginctl user-status dream
pgrep -a -u dream

# 删除账户并删除其家目录（执行前务必确认用户名）
sudo userdel -r dream

# 验证账户已删除；无输出或显示“no such user”均表示本地账户不存在
getent passwd dream
```

## 【4】`passwd`修改密码

`passwd`命令用于修改用户的密码、过期时间等信息，英文全称为`password`，语法格式为`passwd [参数] 用户名`。

普通用户只能使用`passwd`命令修改自己的系统密码，而root管理员则有权限修改其他所有人的密码。

使用 `sudo passwd <用户名>` 可以由管理员重置指定用户的密码。管理员权限很高，应仅在必要时使用，并避免将密码写入笔记、脚本或命令历史。

```bash
passwd   # 修改当前用户密码；长度和复杂度由 PAM 策略决定
# Ubuntu 默认将 root 账户锁定，日常管理优先使用 sudo，而不是为 root 设置密码
```

例如

```bash
linux@ubuntu:~$ sudo adduser ysl
[sudo] linux 的密码：
正在添加用户"ysl"...
正在添加新组"ysl" (1001)...
正在添加新用户"ysl" (1001) 到组"ysl"...
创建主目录"/home/ysl"...
正在从"/etc/skel"复制文件...
输入新的 UNIX 密码：    # 在此输入符合系统策略的新密码
重新输入新的 UNIX 密码： # 再次输入同一个新密码
passwd：已成功更新密码
正在改变 ysl 的用户信息
请输入新值，或直接敲回车键以使用默认值
全名 []:
房间号码 []:
工作电话 []:
家庭电话 []:
其它 []:
这些信息是否正确？ [Y/n]
```

```bash
# 切换用户
linux@ubuntu:~$ su ysl
密码：

# 更改密码
ysl@ubuntu:/home/linux$ passwd
更改 ysl 的密码。
（当前）UNIX 密码：
输入新的 UNIX 密码：     # 在此输入符合系统策略的新密码
重新输入新的 UNIX 密码：  # 再次输入同一个新密码
Bad: new and old password are too similar
输入新的 UNIX 密码：     # 在此输入符合系统策略的新密码
重新输入新的 UNIX 密码：  # 再次输入同一个新密码
passwd：已成功更新密码

# 退出ysl用户, 退回到linux用户
ysl@ubuntu:/home/linux$ exit
exit
linux@ubuntu:~$
```

## 【5】`su`切换用户命令

`su` 用于切换身份。推荐加 `-`（或 `-l`）创建登录 Shell，使 `HOME`、`PATH` 等环境与目标用户一致。
```bash
su - ysl        # 切换到 ysl，并加载其登录环境
sudo -i         # 以 root 的登录环境开启 shell（推荐）
```

例如

```bash
linux@ubuntu:~$ su - root  # Ubuntu 默认 root 账户处于锁定状态，因此认证失败
密码：
su：认证失败

linux@ubuntu:~$ sudo -i  # 使用当前 sudo 用户的密码进入 root 登录 shell
[sudo] linux 的密码：   # 输入linux用户的密码
root@ubuntu:/home/linux#   # 成功进入root用户
root@ubuntu:~# exit
linux@ubuntu:~$
```

## 【6】`sudo`  临时获取权限

`sudo` 让被授权的普通用户以其他用户（默认 root）执行单条命令。认证缓存时长由系统策略决定，不能假定“在一段时间内一定无需验证”。

```bash
sudo apt install gcc g++ # 安装编译器
sudo -v                  # 刷新 sudo 凭据缓存（仅在已获授权时可用）
sudo -k                  # 清除 sudo 凭据缓存，便于结束管理操作后复核
```

# 【补充】验证与故障排查

用 `id 用户名`、`getent passwd 用户名` 验证账户与组，权限变化后重新登录。sudo 被拒绝时检查 `sudo -l`；修改 sudoers 应使用 `visudo`，保留可用管理会话，避免把自己锁在系统外。
