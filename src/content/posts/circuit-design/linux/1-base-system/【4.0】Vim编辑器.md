# 【一】vim 的介绍

`Vim` 是从` vi` 发展出来的一个文本编辑器。代码补全、编译及错误跳转等方便编程的功能特别丰富，在程序员中被广泛使用。

简单来说，`vi` 是传统的屏幕文本编辑器；`Vim`（Vi IMproved）在兼容 vi 的基础上增加了多级撤销、语法高亮、插件和脚本等能力，更适合编写与维护代码。

连 `vim` 的官方网站 (https://www.vim.org/) 自己也说 vim 是一个程序开发工具而不是文字处理软件。

同时关注一下 `nano` 的文本编辑器，比  `vim` 简单。

# 【二】vi 与 vim 之间的关系

`vi` 是一套编辑器接口与传统实现的名称，`Vim` 是兼容 vi 操作方式的独立实现。很多系统中，`vi` 命令会通过软链接或 alternatives 指向 Vim 的精简版或完整版本；可使用 `vi --version`、`vim --version` 查看实际实现。

# 【四】vim 的操作

## 【1】vi 的三种工作模式

普通模式（Normal mode，常被称为“命令模式”）：打开文件后的默认模式，用于移动、删除、复制等编辑操作；此时直接输入的字符不会作为文本插入。

编辑模式 : 编辑文本

命令行模式（Command-line mode）：在普通模式下输入 `:` 后，在底部输入 Ex 命令，例如 `:w`、`:q`。

## 【2】三种模式的切换

普通模式 -> 插入模式：输入 `i`。

插入模式 -> 普通模式：输入 `Esc`。

普通模式 -> 命令行模式：输入 `:`。空格只有在自行映射后才具有该作用。

命令行模式 -> 普通模式：输入 `Esc`。

## 【3】保存退出文件

视图模式 -> 命令模式

```bash
-> :wq  # 保存退出

-> :w   # 只保存

-> :q   # 退出；若有未保存修改，Vim 会拒绝退出

-> :q!  # 强制退出

-> :wq! # 强制写入后退出；用于文件无写权限等情况，仍受实际权限限制

-> :x   # 仅在内容改变时写入并退出

-> :X   # 设置或取消 Vim 自身的简单加密密钥；不适合保护敏感数据
```

问题补充：在某些终端中按下 `Ctrl+S` 会触发终端的软件流控，导致屏幕看似“卡住”；按 `Ctrl+Q` 可恢复。这不是 Vim 锁屏。

## 【4】视图模式下的快捷键

### （1）移动光标

h 向左移动光标

l 向右移动光标

j 向下移动光标

k 向上移动光标

### （2）进入编辑模式

i : 进入编辑模式

o : 新起一行，进入编辑模式，光标移动到开始

a : 光标移动到下一个位置，进入编辑模式

s : 删除一个字符 , 并进入编辑模式

### （3）删除字符

x : 删除光标所在的字符 , 不进入编辑模式

### （4）复制内容

yy : 复制一行

nyy : 复制 n 行

5yy : 复制 5 行

shift + v : 选中一行 ， 上下键选中多行，使用 y 复制选中的内容。

y : 复制选中的内容

### （5）剪切内容

d : 剪切选中的内容

dd : 剪切一行

ndd : 剪切 n 行

3dd : 剪切 3 行

### （6）粘贴内容

p : 在光标后粘贴 Vim 寄存器中的内容；`P` 在光标前粘贴。

### （7）操作的撤销与反撤销

u : 撤销 ， undo

ctrl + r : 反撤销，恢复， redo

### （8）多行选中操作

Shift + v：进入按行可视模式；再用 `j`、`k` 或方向键扩展选择范围。

再使用 y 复制 , 或则 d 剪切 , 最后在使用 p 去粘贴

### （9）文本自动对齐

选中所有 : `ggVG`

使用 `=` 重新缩进文本（是否达到预期效果取决于文件类型和缩进设置）。

### （10）光标移动

gg : 光标移动到文件开始

G : 光标移动到文件末尾

### （11）搜索关键字 : /

`/keyword`

使用 `n` 查看下一个匹配项，使用 `N` 查看上一个匹配项。

# 【五】vim的使用

使用vim编辑一个文件, 保存一个文件, `gcc` 编译一个文件, 再运行一个文件

```bash
linux@ubuntu:~/work$ vi 01-hello.c    # 打开这个文件, 不存在就创建, 存在就打开
linux@ubuntu:~/work$ gcc 01-hello.c   # gcc 编译这个文件
linux@ubuntu:~/work$ ./a.out          # 执行这个可执行程序
hello
linux@ubuntu:~/work$
```

以下是做的一些常用快捷键映射

```vim
" 显示找到的结果，用列表形式
nmap <c-]> g<c-]>          # ctrl + ]  来查找函数定义，结构体定义

" 映射快捷键，ctrl+c 增加 "+y，进行复制
map <C-C> "+y              # 可以把vim中的内容复制到window内的粘贴板

" 映射快捷键，ctrl+v 增加 "+p，进行复制
map <C-V> "+p              # 可以把window中的内容复制到vim内

" 映射快捷键，ctrl+x 调用 "+d，删除选中的内容并写入系统剪贴板
map <C-X> "+d              # 需要 Vim 支持系统剪贴板（+clipboard）

" 映射快捷键，ctrl+z 执行撤销
map <C-Z> u

" 映射快捷键，ctrl+y 执行重做
map <C-Y> <C-R>

" 映射快捷键，ctrl + a 增加 ggVG
map <C-A> ggVG            # ctrl + a 进行全选

" map : -> <space>
map <Space> :              # 把：使用空格进行了一次映射 ，既可以使用 : ，空格也可以进入命令模式
#空格 等价于 冒号
```

练习，使用vim实现7个数组元素的输入并进行冒泡排序后，从大到小的排序并输出。

```c
#include <stdio.h>

void maopao(int *pa, int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        for (int j = 0; j < n - 1 - i; j++)
        {
            if (pa[j] < pa[j + 1])
            {
                int t = pa[j];
                pa[j] = pa[j + 1];
                pa[j + 1] = t;
            }
        }
    }

}

void display_array(const int *pa, int n)
{
    printf("array:");
    for (int i = 0; i < n; i++)
    {
        printf("%d ",pa[i]);
    }
    printf("\n");
}

int main(void)
{
    int a[7] = {0};
    for (int i = 0; i < 7; i++)
    {
        printf("please input %d number >: ", i + 1);
        if (scanf("%d", &a[i]) != 1)
        {
            fprintf(stderr, "invalid input\n");
            return 1;
        }
    }
    display_array(a,7);
    maopao(a,7);
    display_array(a,7);
    return 0;
}
```
