# 【一】测量的目的、工具与基本流程

测量不是“把表笔碰上去读一个数字”，而是用可信的方法回答：**哪里不对、偏离多少、为什么会偏离**。嵌入式硬件调试最常用的工具包括数字万用表、示波器、信号发生器、可调直流电源；电流钳、电子负载、逻辑分析仪、LCR 表和热像仪也常能显著提高排错效率。

```text
先定义问题 → 选择合适仪器与量程 → 正确接入 → 观察数据/波形 → 与预期比较 → 缩小故障范围

例：板卡不上电
电源输入 → 稳压器输入 → 稳压器输出 → 芯片电源脚 → 复位/时钟 → 通信信号
```

## 【1】测量前的安全与防损坏清单

1. **先确认对象与量级**：直流还是交流、预期电压/电流、是否含高压或大储能电容；
2. **先看表笔与插孔**：黑表笔接 COM；红表笔测电压/电阻/通断时接 `VΩ` 孔，测电流时才接 `mA/µA` 或 `10 A` 孔；
3. **不确定量级时先选高量程**，确认后再降低量程提高分辨率；
4. **电阻、通断、二极管、电容档必须在断电状态使用**，且大电容需要先安全放电；
5. **电流表必须串联，电压表必须并联**；把电流档万用表并到电源两端会造成近似短路；
6. 高压/市电场合确认仪表与表笔的 CAT 等级、额定电压和保险丝规格。初学调试不要直接在非隔离市电一次侧测量。

```text
测电压（并联）：
节点 A ●──── 负载 ────● 节点 B
       └──── [ V 表 ] ─┘

测电流（串联）：
电源 + ── [ A 表 ] ── 负载 ── 电源 -
```

> **关键习惯**：电流测完后，立即把红表笔从 `mA/10 A` 孔拨回 `VΩ` 孔。下次若忘记切档就直接测电压，是烧表保险丝的高频原因。

## 【2】仪器读数的可信边界

任何读数都依赖仪器条件：万用表有精度、带宽和输入阻抗限制；示波器探头会给被测点增加电容；信号发生器标称幅度常以 50 Ω 负载为基准。看到异常读数时，先问三个问题：

- 仪器档位、耦合方式、探头倍率和负载设置对吗？
- 仪器本身是否改变了被测电路？
- 测量点的参考地和真正需要比较的两点一致吗？

# 【二】三合一手持设备：便携筛查工具

三合一手持设备通常把数字万用表、小带宽示波器和简易信号发生器整合在一起，适合外出检修、低频信号观察和入门实验。

![三合一手持测量设备外观](https://oss.silentdream.top/2026/10/02/15-05-06-b412c084-O1CN01EmyO7E1UHqID2EqVg_!!2207604222493-1175bb.png)

![三合一手持设备功能界面示例](https://oss.silentdream.top/2026/10/02/15-05-06-ad81d070-O1CN01QnDwgB1UHqID2DIs5_!!2207604222493-3d3139.png)

![三合一手持设备配件/使用场景](https://oss.silentdream.top/2026/10/02/15-05-06-75b86c89-O1CN01R49mM21UHqIChgQkE_!!2207604222493-94b046.png)

## 【1】适合做什么

- 板卡直流电压、通断、电阻和二极管的快速检查；
- 低频 PWM、按键抖动、串口波形、555/传感器等信号的粗略观察；
- 用小幅度方波/正弦波做简单注入测试；
- 外出维修时初步判断“有无供电、时钟有没有、信号是否变化”。

## 【2】不应替代什么

手持设备的示波器带宽、采样率、存储深度、输入保护和探头配置通常有限；它不适合用来判断高速 USB、DDR、开关电源尖峰、射频信号或高压安全问题。需要精确纹波、EMI、协议或高速信号分析时，应使用台式示波器、差分探头、逻辑分析仪或频谱仪等专用工具。

# 【三】数字万用表（DMM）

## 【1】功能、表笔与档位

![数字万用表的旋钮、插孔与功能概览](https://oss.silentdream.top/2026/10/02/15-05-06-f0372939-O1CN01xLjUIf1UHqIChhEeq_!!2207604222493-4abf1a.png)

数字万用表通常集成直流/交流电压、电流、电阻、通断、二极管、电容、频率、温度等功能；不同表型支持的量程、真有效值、输入阻抗和安全等级不同，以本机面板和说明书为准。

| 表笔位置 | 常见用途 | 注意事项 |
| --- | --- | --- |
| COM | 黑表笔公共端 | 所有测量都接此孔 |
| VΩHz（或 VΩ） | 电压、电阻、通断、二极管、电容、频率 | 内阻通常高，适合并联测电压 |
| mA/µA | 小电流 | 往往带保险丝，允许电流/时间有限 |
| 10 A/20 A | 大电流 | 常是独立量程，精度和持续时间有限 |

## 【2】测量直流与交流电压

### （1）直流电压（DCV）

直流电压表并联在需要比较的两点之间。红笔接高电势点、黑笔接参考点时读正值；出现负号只表示极性与预期相反。

![直流电压档与表笔连接](https://oss.silentdream.top/2026/10/02/15-05-06-2f70daf0-image-20261002144724288-1c345d.png)

```text
测 MCU 3.3 V：黑笔接板上 GND，红笔接 3V3 电源点
测某电阻压降：两支表笔分别接电阻的两端，不能只测其中一端对地
```

测开关电源输出时，万用表读到的是平均/低频意义上的数值，看不到高频纹波和瞬态；若要判断纹波、启动过冲或掉电过程，应改用示波器。

### （2）交流电压（ACV）

![交流电压档与表笔连接](https://oss.silentdream.top/2026/10/02/15-05-06-6cfc552b-image-20261002144628790-89f741.png)

交流档通常读有效值。只有标注 **True RMS（真有效值）** 且带宽覆盖被测信号的仪表，才能较准确地测量非正弦波；低价表的 AC 档常假设正弦波，对 PWM、开关电源纹波等读数可能没有意义。

![交流电压测量示例](https://oss.silentdream.top/2026/10/02/15-05-06-6ba45238-image-20261002144657499-e0caca.png)

市电测量只在确认仪表、表笔和操作能力都符合要求时进行。不要通过万用表“单笔悬空试探”来判断安全；应使用符合当地规范的双极验电器/专业测试方法，并由具备资质人员操作。

## 【3】测量电流：最容易烧表的功能

### （1）大电流档

![10 A 档的插孔与量程示意](https://oss.silentdream.top/2026/10/02/15-05-06-a9b7206d-image-20261002144807367-137f25.png)

大电流档通常把表内低阻分流电阻串到回路中，必须断电后接入，通电后读取。先确认该档允许的最大电流和连续时间；许多表的 10 A 档只允许短时测量。

### （2）小电流档

![mA/µA 档的插孔与量程示意](https://oss.silentdream.top/2026/10/02/15-05-06-13711b52-image-20261002144843133-fe2802.png)

小电流档分辨率高，但保险丝额定值通常更低。测低功耗 MCU 的 µA 级休眠电流时，仪表的 burden voltage（串联压降）可能使被测系统电压下降，改变真实工作状态。

```text
更安全的排查顺序：
先用电源限流功能或串联较大分流电阻判断是否短路
再用电流档精测
大电流/不可断回路优先用电流钳或分流电阻 + 示波器
```

## 【4】电阻、通断与电容

### （1）电阻档

![电阻测量档位](https://oss.silentdream.top/2026/10/02/15-05-06-4a553ed1-image-20261002144908212-9db399.png)

电阻档由万用表向被测件施加小测试电流/电压，再反推阻值，因此**必须断电**。在电路板上测量会受并联支路影响；要确认单个电阻值时，必要时抬起一个引脚。

### （2）通断档

![通断蜂鸣档](https://oss.silentdream.top/2026/10/02/15-05-06-7608c364-image-20261002144951462-4b5197.png)

通断蜂鸣只表示阻值低于仪表设定阈值，不等于一定是“短路”。例如线圈、低阻电阻、MOSFET 导通通路都会鸣叫；应结合电阻读数、原理图和器件状态判断。

### （3）电容档

![电容测量档位](https://oss.silentdream.top/2026/10/02/15-05-06-ce703a28-image-20261002144925585-f9b404.png)

先断电并用合适电阻安全放电，再取下或至少抬起电容一端测量。万用表的电容档通常不能测 ESR、漏电、额定电压下的 DC Bias 容量或高频特性；判断电源电容健康还需要 ESR 表、LCR 表或示波器纹波测试。

## 【5】二极管档与火零线安全说明

### （1）二极管档

![二极管测试档](https://oss.silentdream.top/2026/10/02/15-05-06-baae2325-image-20261002145020028-395d2c.png)

二极管档显示的是测试电流下的正向压降：红笔接阳极、黑笔接阴极时，普通硅二极管常显示约 0.5～0.8 V，肖特基常更低；调换表笔一般应显示过量程。结果会受并联元件影响，不能只凭一次读数给出结论。

### （2）关于火线/零线

![原笔记中的火零线识别示意](https://oss.silentdream.top/2026/10/02/15-05-06-7aeece39-image-20261002145042504-1ae52e.png)

市电线路的火线、零线和保护地判断涉及触电风险，不能依赖单一万用表读数或“悬空表笔”方法。工程现场应遵循断电、验电、挂牌/上锁等安全流程，使用符合规范的双极验电器、相序表或由合格电工处理。切勿在电阻、通断、电流档上接触市电。

# 【四】示波器：看见电压随时间的变化

![台式/手持示波器示例](https://oss.silentdream.top/2026/10/02/15-05-06-e88cd845-O1CN01iWCn5e1UHqIB6Macf_!!2207604222493-3d71ab.png)

示波器显示的是 `电压—时间` 波形，适合观察时钟、PWM、复位、串口、I²C、开关电源纹波、按键抖动和传感器瞬态。它能回答万用表无法回答的问题：信号有没有跳变、频率多少、边沿多快、噪声在哪里、什么时候出现异常。

![示波器的基础操作/界面示意](https://oss.silentdream.top/2026/10/02/15-05-06-36de55c9-image-20261002145351705-c03759.png)

## 【1】先理解四个基本量

```text
垂直档（V/div） ：一格代表多少伏，决定幅度显示
水平档（s/div） ：一格代表多少秒，决定时间展开
触发（Trigger） ：在可重复的条件下开始采集，使波形稳定
探头倍率（1×/10×）：必须同时在探头和示波器通道菜单中设置一致
```

示波器显示的幅度、频率和上升沿真实性还受带宽、采样率、存储深度和探头影响。经验上，要观察某一频率信号的基本形状，带宽应至少高于该频率数倍；要分析快速边沿和振铃，则要求更高。

## 【2】安全接地：最重要的示波器规则

大多数台式示波器 BNC 外壳和探头地夹连接到保护地。把地夹夹在非隔离市电一次侧、半桥开关节点或浮地高压点，可能直接造成短路、电弧、仪器损坏和人身危险。

```text
普通单端探头：地夹 = 示波器保护地

安全的低压板卡：地夹接系统 GND，探头尖端接被测节点
浮地/高压两点之差：使用差分探头、隔离测量方案或专业设备
```

不要用“把示波器地线剪掉”来规避这一限制。那会破坏保护接地并产生更大风险。

## 【3】探头、耦合与补偿

- **10× 探头**：输入电容更低、耐压更高、对电路扰动更小，是大多数数字电路的优先选择；
- **探头补偿**：首次使用或更换通道后，用示波器校准方波调整探头补偿，避免方波边沿过冲/钝化由探头本身造成；
- **DC 耦合**：观察直流加交流成分；**AC 耦合**：隔离直流偏置、放大观察小纹波；**GND 耦合**：确认零电平位置；
- 测开关电源纹波使用短地弹簧，长地夹会形成大环路并引入假尖峰。

## 【4】常见测量构图

```text
测 3.3 V 纹波：探头尖端 → 3V3，短地弹簧 → 就近 GND，AC 耦合，合适 V/div
测 UART：CH1 → TX，CH2 → RX，两个地夹都接同一系统 GND
测 PWM：触发源选 PWM 通道，上升沿触发，s/div 显示数个周期
测 I²C：同时看 SCL/SDA，关注起始、停止和 ACK 时刻
```

# 【五】信号发生器：向电路注入可控刺激

![信号发生器示例](https://oss.silentdream.top/2026/10/02/15-05-06-f807bda5-O1CN01o1e9751UHqIB6GsW1_!!2207604222493-84c31b.png)

信号发生器（函数发生器/任意波形发生器）可输出正弦、方波、三角波、脉冲和任意波形，用于验证放大器、滤波器、比较器、ADC 输入链、蜂鸣器和通信电路。

## 【1】最常设置的参数

| 参数 | 含义 | 常见误区 |
| --- | --- | --- |
| 波形 | 正弦/方波/三角/脉冲 | 方波边沿快，可能超出被测电路带宽 |
| 频率 | 每秒周期数 | 先从低频开始，确认后逐步提高 |
| 幅度 | Vpp、峰值或 RMS | 必须确认仪器显示的单位与负载条件 |
| 偏置 | 整个波形上移/下移 | 防止负半周低于芯片 GND 或超过 VDD |
| 占空比 | 高电平占周期比例 | PWM/脉冲实验时需单独设置 |

## 【2】50 Ω 输出与幅度陷阱

许多台式信号发生器输出端等效为 50 Ω，屏幕幅度可能按“接 50 Ω 终端”标定。若接到示波器 1 MΩ 输入或高阻电路，实际幅度可能与设定不同（常见约翻倍，具体以仪器设置为准）。

```text
信号源（50 Ω） ──→ 被测高阻输入
                  └─ 应确认发生器的 Load 设定为 High Z 或 50 Ω
```

初次注入时使用小幅度、合适偏置，先用示波器在被测点确认实际波形，再接入敏感 IC。信号发生器地通常与保护地关联，连接到非隔离高压系统前也必须审查接地风险。

# 【六】常用配套工具：让测量更完整

## 【1】可调直流电源

实验室电源的核心价值是**限压、限流、可观察**。给新板首次上电时，应先设正确电压和较低电流限制；若电流立刻顶到限流，先排查短路而不是不断提高限流。

```text
首次上电建议：
设定额定电压 → 电流限值从较低开始 → 观察电流 → 测关键电源轨 → 再逐步加载
```

注意恒压（CV）与恒流（CC）状态：进入 CC 说明电源在主动降低输出电压限制电流，此时板卡可能并未得到额定电压。

## 【2】电子负载与电流钳

- **电子负载**：模拟恒流、恒阻、恒功率等负载，适合测试 LDO/DC-DC 的带载能力、瞬态和温升；
- **电流钳**：无需断开回路即可测直流/交流电流，适合大电流和纹波观察；先检查量程、零点和带宽；
- **分流电阻**：低成本测电流的方法，但需核算功耗与压降，并用差分测量避免把示波器地夹接错。

## 【3】逻辑分析仪、LCR 表与热像仪

- **逻辑分析仪**：同时抓取多路 SPI、I²C、UART、CAN 等数字时序，适合协议层排错；要确认采样率、阈值和是否有共地；
- **LCR 表**：在指定频率/测试电平下测电感、电容、电阻以及 ESR/Q，适合元件筛选与失效判断；
- **热像仪/温度探头**：快速定位 LDO、MOSFET、电感和连接器热点；温度是功耗和接触不良的重要线索。

# 【七】一套可复用的板卡排错流程

## 【1】上电前

1. 目检极性、焊桥、缺件、连接器与丝印；
2. 断电测电源对地阻值，注意大电容充电会让读数变化；
3. 确认可调电源电压与限流、万用表表笔插孔和档位；
4. 预先规划哪些点要测：输入、各级输出、复位、时钟、通信线。

## 【2】上电后按“电源—时钟—复位—通信—功能”推进

```text
电源是否正确？
    ↓
时钟是否振荡？
    ↓
复位是否释放？
    ↓
调试串口/下载接口是否有波形？
    ↓
外设和业务信号是否按时序工作？
```

每一步都记录“预期值、实际值、测量点、仪器设置”。这比反复更换元件更快，也能让后续复现和协作有据可查。

## 【3】最终自检

- 直流读数异常时，是否改用示波器检查了纹波和瞬态？
- 示波器探头倍率、地夹位置、耦合和触发是否正确？
- 测电流时是否确认了串联关系和表笔插孔？
- 连接 USB、信号发生器、示波器时，是否确认了所有设备的地参考？
- 高压/市电是否已停止自行试探，并改用合规仪器与专业流程？
