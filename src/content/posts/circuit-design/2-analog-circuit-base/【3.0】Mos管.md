# 【一】什么是 MOS 管

MOS 管通常指 MOSFET（Metal-Oxide-Semiconductor Field-Effect Transistor，金属—氧化物—半导体场效应晶体管）。它是**电压控制型**器件：栅极 G 与沟道之间有绝缘层，稳态时栅极几乎不需要直流电流，却可通过栅源电压控制漏极 D 与源极 S 之间的导通程度。

常见引脚名称：

- `G`（Gate）：栅极，控制端；
- `D`（Drain）：漏极，主电流端；
- `S`（Source）：源极，主电流端。

![MOSFET 引脚和符号示意](https://oss.silentdream.top/2026/10/01/10-34-54-86ed6178-image-20261001094443335-5c8ecb.png)

> **读图提示**：同一封装内的 G/D/S 排列并不通用，散热焊盘也常与 D 相连。画 PCB 封装或手工接线前，必须核对具体型号的数据手册。

# 【二】MOSFET 的构造

以增强型 N 沟道 MOSFET 为例，器件通常以 P 型衬底为基础，在表面形成两个 N 型区域作为源极和漏极；栅极与半导体之间隔着很薄的氧化层。给栅极施加相对源极足够高的正电压时，表面形成可导电的 N 型沟道，D 与 S 之间即可导通。

![增强型 N 沟道 MOSFET 的基本结构](https://oss.silentdream.top/2026/10/01/10-34-54-3a3f7360-image-20261001094617752-d12b70.png)

栅极氧化层带来很高的输入阻抗，也使其容易被静电击穿。未焊接器件应保存在防静电包装中；设计中应避免栅极悬空，并在接口、人工接触或长走线场景考虑加栅极串联电阻、下拉电阻和 ESD 保护。

# 【三】MOSFET 分类

按沟道和工作方式可分为四类：

| 沟道 | 增强型 | 耗尽型 |
| --- | --- | --- |
| N 沟道 | 最常见；`V_GS` 足够高才增强导通 | `V_GS = 0` 时可导通，负栅压可减弱 |
| P 沟道 | `V_GS` 为负且绝对值足够大时导通 | `V_GS = 0` 时可导通，正栅压可减弱 |

![不同类型 MOSFET 的符号/分类](https://oss.silentdream.top/2026/10/01/10-34-54-6faf0bc4-image-20261001094847851-b6ff22.png)

嵌入式电源和负载开关中最常见的是增强型 N-MOS 与 P-MOS。N-MOS 的导通电阻通常更低，适合低端开关和同步降压；P-MOS 高端驱动较直观，但同面积下导通电阻常更大。

# 【四】工作原理与动态特性

## 【1】栅源电压才是控制量

控制 MOSFET 的关键不是栅极相对地的电压，而是：

```text
V_GS = V_G − V_S
```

对 N-MOS，`V_GS` 为正且足够大时导通；对 P-MOS，`V_GS` 为负且绝对值足够大时导通。高端开关中源极电位会随负载上升，若只用地参考的 GPIO 直接驱动 N-MOS 栅极，`V_GS` 可能不足，器件会处于半导通并严重发热。

## 【2】阈值电压不等于完全导通电压

![MOSFET 导通控制的示意](https://oss.silentdream.top/2026/10/01/10-34-54-7ce87427-image-20261001094931006-8c4b53.png)

数据手册中的 `V_GS(th)` 通常是在极小漏电流条件下测得，只表示“刚开始导通”，**不代表适合带载开关**。设计应查看数据手册是否明确给出了目标栅压（如 2.5 V、3.3 V、4.5 V 或 10 V）下的 `R_DS(on)` 最大值。

```text
N-MOS 低端开关的状态：

V_GS = 0 V                 V_GS 足够高
DS 近似断开                 DS 近似为小电阻 R_DS(on)
```

## 【3】栅极像电容，需要充放电

MOSFET 栅极的直流电流很小，但开关瞬间必须给栅极电荷 `Q_g` 充放电。驱动电流不足会使开关沿变慢，导致 MOSFET 在高电压和大电流同时存在的线性区停留更久，开关损耗和 EMI 都会增加。

```text
GPIO / 驱动器 ── R_G ── G
                         │
                      MOSFET
                         │
                       R_PD
                         │
                        GND

R_G 限制栅极尖峰和振铃；R_PD 在上电/复位时把栅极拉到确定的关断状态
```

# 【五】MOSFET 与三极管对比

| 项目 | MOSFET | BJT 三极管 |
| --- | --- | --- |
| 控制方式 | 主要由栅源电压控制 | 需要持续基极电流 |
| 稳态驱动功耗 | 理想情况下很低 | 基极驱动会持续耗电 |
| 导通损耗 | 近似由 `I² × R_DS(on)` 决定 | 近似由 `V_CE(sat) × I_C` 决定 |
| 高速开关限制 | 栅极电荷、寄生电容、驱动回路 | 存储电荷、基极驱动 |
| 常见优势 | 大电流开关、PWM、电源转换 | 小电流放大、低成本简单开关 |

两者没有绝对替代关系。小电流、低速、成本敏感的场景，BJT 仍然实用；低压大电流或高频 PWM 场景，逻辑级 MOSFET 通常更合适。

# 【六】典型应用与构图说明

## 【1】N-MOS 低端开关

```text
VCC ── 负载 ── D
                 │
               N-MOS
                 │
                S ── GND

MCU GPIO ── R_G ── G
                  │
                R_PD
                  │
                 GND
```

GPIO 输出高电平时，若 `V_GS` 足够，N-MOS 导通，电流从 VCC 经负载流向 GND。该结构适合 LED 灯带、电机、继电器和电磁阀。感性负载必须加续流二极管或合适钳位器件；二极管要靠近负载/开关回路放置。

## 【2】P-MOS 高端开关

```text
VCC ── S  P-MOS  D ── 负载 ── GND
          │
          G ── 上拉到 VCC：关断
          G ── 被拉低：V_GS 为负，导通
```

P-MOS 可直接切断负载正端，适合需要“高端断电”的场合。注意绝对最大额定值 `V_GS(max)`：输入电压较高时，栅极不能直接拉到地，常需齐纳钳位或分压/驱动器保护栅氧层。

## 【3】PWM 与开关电源

MOSFET 可用 PWM 调节平均功率，例如调光、调速和同步 Buck。PWM 频率越高，电感/电容滤波更容易做小，但栅极驱动和开关损耗更大。驱动电机、变压器或半桥时，除了续流路径，还要处理死区时间、交叉导通和布局寄生电感。

# 【七】选型、损耗与 PCB 布局

## 【1】关键参数

| 参数 | 说明 | 选型注意 |
| --- | --- | --- |
| `V_DSS` | 漏源耐压 | 覆盖电源最高电压与尖峰，并留余量 |
| `R_DS(on)` | 导通电阻 | 必须看目标 `V_GS`、温度下的最大值 |
| `I_D` / SOA | 电流与安全工作区 | 不只看数据表首页峰值，需看热条件与脉冲曲线 |
| `Q_g` | 总栅极电荷 | 决定驱动电流和高频开关损耗 |
| `V_GS(max)` | 栅源最大耐压 | 常见为 ±20 V，但型号不同，绝不能想当然 |
| 体二极管参数 | 内建 PN 结的特性 | 半桥、反接和感性回路必须考虑其导通路径 |
| 热阻与封装 | 散热能力 | 受铜皮面积、过孔和风冷条件影响很大 |

## 【2】导通损耗与开关损耗

导通损耗可先估算为：

$$
P_{cond}\approx I_D^2R_{DS(on)}
$$

`R_DS(on)` 会随结温升高而增大。高频 PWM 还要叠加开通/关断损耗、栅极驱动损耗和体二极管反向恢复损耗；仅用导通电阻估算会低估实际温升。

## 【3】布局要点

- 大电流回路要短、宽，输入去耦电容紧贴开关管和负载回路；
- 栅极走线短且远离漏极开关节点，避免被高 `dv/dt` 干扰误导通；
- 功率 MOSFET 的散热焊盘/铜皮按数据手册建议铺设，并用热过孔连接内层铜；
- 电流采样、反馈和 MCU 地线不要与大电流回流共用细长路径；
- 示波器测开关节点时使用短地弹簧或差分探头，避免长地线制造“假振铃”。

![NMOS 截止状态仿真](https://oss.silentdream.top/2026/10/01/10-34-54-2866359d-image-20261001095353744-82421f.png)

观察 `V_GS`、`V_DS`、漏极电流和负载电压：栅极低电平时 MOSFET 截止；栅极高电平且 `V_GS` 足够时导通。随后尝试提高负载电流或降低栅压，体会“阈值电压不等于充分导通”的差别。
