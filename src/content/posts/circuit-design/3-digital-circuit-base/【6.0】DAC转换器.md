# 【一】DAC：让数字代码变成模拟输出

DAC（Digital-to-Analog Converter，数模转换器）把有限位宽的数字代码转换为对应的模拟电压或电流。它用于音频播放、波形发生、可编程基准、执行器控制、偏置设定和通信发射等场景。

![ADC 与 DAC 构成模拟—数字—模拟链路](https://oss.silentdream.top/2026/10/02/01-12-28-77e1269b-image-20261001222020795-917810.png)

```text
数字代码 → DAC 核心 → 输出缓冲/重建滤波 → 模拟负载
   ↑              ↑              ↑
 更新时钟        VREF          负载/带宽
```

> **读图提示**：DAC 的输出通常不是天然“光滑的连续曲线”，而是在更新时刻改变并保持到下一次更新的阶梯波。输出缓冲、低通重建滤波和参考电压决定最终模拟质量。

# 【二】核心概念与理想传递关系

## 【1】输入、输出与代码范围

`N` 位无符号 DAC 的输入代码通常为 `0` 到 `2^N − 1`。单极性电压输出的理想关系常写为：

$$
V_{OUT}\approx\frac{Code}{2^N-1}V_{REF}
$$

不同 DAC 对“满量程输出”和 1 LSB 的定义可能不同：有的以 `V_REF / 2^N` 定义步进，有的把最大码定义为接近 `V_REF`。精密设计、软件标定和跨芯片替换时，一定以具体数据手册传递函数为准。

## 【2】分辨率与阶梯输出

理想 LSB 步进近似为：

$$
LSB\approx\frac{V_{REF}}{2^N}
$$

```text
数字代码：  000  001  010  011  100
DAC 输出：  ──┐__┌──┐__┌──┐__┌──  ← 零阶保持的阶梯波
```

位数越高，理论台阶越细；但噪声、参考误差、线性度、输出缓冲和负载变化仍可能掩盖低位。对于 16 位及更高精度 DAC，PCB 泄漏、热电势和参考噪声都可能达到多个 LSB。

## 【3】电压输出与电流输出

| 输出形式 | 特点 | 常见用途 |
| --- | --- | --- |
| 电压输出 DAC | 使用方便，常内置缓冲 | MCU 外置模拟控制、低速波形 |
| 电流输出 DAC | 线性/速度潜力好，常需外部 I/V 转换 | 高速通信、精密信号链 |
| PWM + 滤波 | 不是严格 DAC，但成本低 | 调光、低精度控制、简单音频 |

PWM 的平均电压约由占空比决定，但纹波、响应时间和负载相关性与真正 DAC 不同。需要低噪声、直流精度或快速建立时，应优先选 DAC。

# 【三】DAC 的实现原理

## 【1】电阻串（开关树）型

电阻串把参考电压均分为很多抽头，开关/多路选择器选择其中一个电平输出。

![开关树/电阻串型 DAC](https://oss.silentdream.top/2026/10/02/01-12-28-aab158bc-image-20261001222306354-3518e3.png)

优点是单调性容易保证、只需一种阻值；缺点是 `N` 位需要约 `2^N` 个电阻段和大量开关，位数升高时面积迅速增大。因此常用于较低位数、需要单调性的片上 DAC。

## 【2】二进制权电阻网络

每一位通过按 1、2、4、8… 比例加权的电阻或电流贡献到求和节点，MSB 权重最大，LSB 权重最小。

![二进制位权重示意](https://oss.silentdream.top/2026/10/02/01-12-28-c3d305fe-image-20261001222339111-ba24cf.png)

![权电阻网络 DAC](https://oss.silentdream.top/2026/10/02/01-12-28-c1559e07-image-20261001222403582-a2cd3f.png)

它概念直观，但高位数需要跨度很大的精密电阻比，制造一致性困难；开关导通电阻也会引入误差，因此现代集成 DAC 更多采用 R-2R 或电流舵结构。

## 【3】R-2R 梯形网络

R-2R 网络只使用 `R` 和 `2R` 两种阻值，通过重复的电阻结构产生二进制权重，是很常见的电压/电流 DAC 基础。其优势是电阻比易于在同一芯片上匹配；外部离散电阻搭建时仍会受容差、温漂、开关阻抗和寄生电容影响。

```text
每一位开关接 VREF 或 GND
D_MSB ──┬─ R ─┬─ R ─┬─ R ─→ 求和/缓冲
        │      │      │
       2R     2R     2R
        │      │      │
      开关    开关    开关
```

## 【4】权电流/电流舵型

电流舵 DAC 用按二进制权重或等权分段的恒流源，通过高速开关把电流导向输出或参考端。

![权电流型 DAC](https://oss.silentdream.top/2026/10/02/01-12-28-d15822ee-image-20261001222423609-6bdce3.png)

它适合高速和高频应用，可减小输出电压摆动对开关的影响；但对恒流源匹配、开关时序、寄生电容和 I/V 转换器要求更高。高速 DAC 常采用分段结构：高位用温度计码减少大跳变，低位用二进制权重兼顾面积与速度。

# 【四】更新、保持与重建滤波

## 【1】零阶保持与镜像频谱

DAC 每次更新后保持上一个输出至下次更新，称为零阶保持。即使数字数据是理想正弦，输出也会包含采样频率及其倍频附近的镜像成分，因此需要模拟低通重建滤波器。

```text
DAC 阶梯输出 ──→ [ 低通重建滤波器 ] ──→ 平滑目标波形
                    ↑
           截止频率略高于目标带宽、低于镜像区域
```

滤波器与更新率必须协同设计：更新率越高，镜像频率越远，滤波器设计越容易；但 DAC 的建立时间、接口带宽和功耗也会提高。

## 【2】毛刺（Glitch）

代码切换时，多位开关不会完全同时动作，尤其是从 `011...111` 跳到 `100...000` 时，输出可能产生很窄的错误脉冲，称为毛刺。

```text
理想阶跃：  ──────┐
                  └──────
实际切换：  ────┐╲╱└─────  ← 短暂毛刺
```

音频、精密控制和高速波形应用需关注数据手册的 glitch impulse。可通过同步更新、输出缓冲、适当低通滤波、温度计码/分段结构和减少数字串扰来减轻。

# 【五】典型应用与接口设计

## 【1】可编程基准/模拟控制

```text
MCU SPI/I²C ──→ DAC ──→ 运放缓冲 ──→ 控制电压/阈值/执行器
                         │
                       RC 滤波
```

用于调节 LED 恒流驱动的参考、设定电源反馈、模拟阈值或阀门控制。必须确认 DAC 输出摆幅、负载电流和运放输入/输出范围；DAC 输出脚未必能直接驱动外部负载。

## 【2】音频与波形发生

音频 DAC 应特别关注采样率、SNR、THD+N、输出滤波和模拟地。用 MCU 查表生成波形时，查表点数、更新定时抖动与低通滤波共同决定失真，而不是“有一个 DAC 引脚”就能输出高质量正弦波。

## 【3】参考与布局

- VREF 决定输出比例，必须使用低噪声基准或明确校准；
- 数字接口时钟线远离 VREF 和高阻模拟输出；
- DAC、缓冲运放和输出滤波器紧凑放置，保持连续低阻抗地回流；
- 若输出连接外部接口，考虑 ESD、浪涌、短路和电缆电容下的运放稳定性。

# 【六】调试与常见错误

| 现象 | 常见原因 | 检查方法 |
| --- | --- | --- |
| 输出幅度不对 | VREF、增益设置、满量程定义误解 | 测 VREF，读手册传递函数 |
| 小码不变化 | 分辨率受噪声/负载/仪表限制 | 断开负载、示波器/万用表换合适量程 |
| 阶跃后迟迟稳定 | 建立时间、输出缓冲、RC 过大 | 同时测 DAC 脚和缓冲输出 |
| 输出有尖峰/杂散 | 毛刺、数字串扰、接地不良 | 用短地探头观察更新瞬间 |
| 输出失真 | 更新率不足、重建滤波不当、负载过重 | 检查采样频率、滤波器和缓冲能力 |
