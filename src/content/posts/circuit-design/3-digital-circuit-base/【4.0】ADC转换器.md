# 【一】ADC：把模拟量带入数字系统

ADC（Analog-to-Digital Converter，模数转换器）把连续变化的模拟电压或电流转换为有限位宽的数字代码。温度、压力、光照、声音和电池电压等物理量本身大多是模拟量；MCU、DSP 和 FPGA 要处理它们，通常需经过传感器、信号调理与 ADC。

![模拟量经 ADC 进入数字处理、再经 DAC 输出的链路](https://oss.silentdream.top/2026/10/02/01-12-28-95c32216-image-20261001220950935-a86e18.png)

```text
物理量 → 传感器 → 放大/滤波/保护 → ADC → MCU/DSP → 通信/存储/控制
                                  ↑
                                VREF 与时钟
```

> **读图提示**：ADC 不是孤立元件。前端阻抗、抗混叠滤波、参考电压、时钟、供电和接地都会影响最终读数；“标称 12 位”不等于系统一定能得到 12 位有效信息。

# 【二】转换流程与基本概念

## 【1】采样：把连续时间变为离散时间

ADC 每隔一个采样周期读取输入瞬时值。为避免高频信号“伪装”成低频信号（混叠），采样频率应至少高于信号最高有效频率的两倍；实际工程还要为滤波器过渡带留余量，并在 ADC 前放置模拟低通抗混叠滤波器。

```text
连续模拟波形：   ~~~~~~~~
采样时刻：       ·  ·  ·  ·  ·
离散样本：       |  |  |  |  |

若采样率不足，高频成分会折叠到低频，软件无法在事后完全恢复。
```

## 【2】保持：让输入在转换期间稳定

许多 ADC 内部有采样保持（S/H）电路：采样开关闭合时，内部小电容跟随输入；转换时开关断开，电容短时保持采到的电压。

![采样保持电路基本形式](https://oss.silentdream.top/2026/10/02/01-12-28-879828bc-image-20261001221335702-88ba97.png)

> **读图提示**：内部采样电容需要在采样窗口内充到足够准确。因此 ADC 输入并不是“无限高阻”；当外部源阻抗太大、采样时间太短时，会产生建立误差。MCU 手册通常给出最大推荐源阻抗或最小采样周期。

## 【3】量化：把连续幅度映射到有限台阶

`N` 位 ADC 有 `2^N` 个代码。以单极性 0～`V_REF` 输入范围为例，一个 LSB 的典型理想间隔近似为：

$$
LSB\approx\frac{V_{REF}}{2^N}
$$

量化必然带来误差。理想 ADC 的量化误差通常在约 ±0.5 LSB 内；提高位数可减小台阶大小，但不能自动消除参考噪声、传感器噪声、非线性或布局干扰。

```text
模拟输入：  连续斜坡  / 
数字代码：  0 ─┐__┌__┌__┌__  → 台阶状
                1  2  3  4
```

## 【4】编码：输出为二进制代码

量化后的级别被编码为二进制、补码、格雷码或串行数据流。MCU 内置 ADC 通常把结果放入寄存器；外置 ADC 则常通过 SPI、I²C、并口或 LVDS 等接口输出。要确认数据对齐、符号格式、字节序、有效位与状态位的定义。

# 【三】ADC 输入范围与代码换算

## 【1】单端、差分与参考电压

```text
单端输入： Vin 相对 AGND 测量
差分输入： VinP 与 VinN 的差值测量

Vin ──→ ADC_IN                 VinP ──→ ADC +
AGND ─→ AGND                   VinN ──→ ADC −
```

参考电压 `V_REF` 定义 ADC 的量程和比例尺。若参考随电源或温度漂移，所有读数会按比例变化；测量精度往往先受 VREF 质量限制。输入脚的绝对最大额定值、允许共模范围和参考范围必须分别查手册。

## 【2】理想换算关系

对常见无符号单极性 ADC，代码范围为 `0` 到 `2^N − 1`。把数字码换算为电压时，常用近似为：

$$
V_{IN}\approx\frac{Code}{2^N-1}V_{REF}
$$

不同厂商对满量程端点、LSB 定义和饱和代码的约定可能不同；高精度应用应以数据手册的传递函数为准，而不是只套一个通用公式。

# 【四】常见 ADC 架构

## 【1】并联比较型（Flash）

Flash ADC 用电阻串产生多个阈值，由大量比较器并行比较，再由编码器输出数字码。

![并联比较型 ADC 结构](https://oss.silentdream.top/2026/10/02/01-12-28-f1219082-image-20261001221538768-afbb8e.png)

速度极高，但 `N` 位转换器理论上需要 `2^N − 1` 个比较器，功耗、面积和失配校准成本快速增加。因此常用于低到中等位数的高速采样、视频或通信前端。

## 【2】逐次逼近型（SAR）

SAR ADC 由采样保持、比较器、内部 DAC 和逐次逼近寄存器组成；它像二分查找一样从最高位到最低位逐位试探。

![逐次逼近型 ADC 结构](https://oss.silentdream.top/2026/10/02/01-12-28-d26b394c-image-20261001221620607-6292a3.png)

```text
先试 MSB → 比较 Vin 与内部 DAC → 保留/清除该位
再试下一位 → 重复比较
N 位转换通常需约 N 个比较时钟
```

SAR 在速度、功耗、成本和分辨率之间平衡良好，是 MCU 内置 ADC 和通用采集系统的主流架构。它要求采样期间输入建立充分，参考电压在转换过程中稳定。

## 【3】双积分型（Dual-Slope）

双积分 ADC 先在固定时间内对输入积分，再用已知参考反向积分到零；第二段时间与输入电压成比例。

![双积分型 ADC 结构](https://oss.silentdream.top/2026/10/02/01-12-28-0ebd60b3-image-20261001221739019-8c6e46.png)

它对工频等周期性干扰有很强抑制，适合万用表、面板表和低速高稳定测量；代价是转换速度低，不适合高速波形采样。

## 【4】Σ-Δ（Sigma-Delta）

Σ-Δ ADC 以较高的内部过采样率工作，利用调制器把量化噪声推向高频，再由数字滤波器与抽取器得到高分辨率低速输出。

![Σ-Δ ADC 基本结构](https://oss.silentdream.top/2026/10/02/01-12-28-0727777a-image-20261001221820046-2e196a.png)

它适合音频、称重、温度和精密低带宽测量。数字滤波会带来群延迟；切换通道或输入阶跃后，需要等待滤波器稳定，不能把数据率直接等同于即时响应速度。

## 【5】电压—频率型（V/F）

V/F ADC 先把电压转换为频率或脉冲密度，再在固定时间窗内计数。

![电压—频率型 ADC 结构](https://oss.silentdream.top/2026/10/02/01-12-28-dd4520e1-image-20261001221855784-dccb59.png)

该方法接口直观、适合长距离和抗干扰计数传输，但转换速度与分辨率受计数时间限制。它现在较少作为通用 ADC 主流架构，但在特定工业测量中仍可见。

# 【五】前端设计与布局

## 【1】保护、缩放与驱动

```text
被测信号 ── R ──●── ADC_IN
                 │
               C 到地        ← 抗混叠/采样电荷缓冲
                 │
                GND

可选：TVS/钳位、分压、运放缓冲、隔离
```

- 确保任何正常和故障条件下，ADC_IN 都不超过绝对最大额定值；
- 分压电阻既要控制静态功耗，也要满足采样保持建立时间；
- 输入 RC 截止频率需同时考虑信号带宽和采样频率；
- 运放缓冲器要能驱动采样电容，并在电源/共模范围内稳定工作。

## 【2】供电、参考与地

- 参考电压走线短、干净，并按资料要求使用去耦电容；
- 数字时钟、高速 GPIO 和开关电源远离 ADC 输入与 VREF；
- 模拟地与数字地通常在芯片/参考设计指定处连接，不能随意长距离分割导致回流绕路；
- 用 MCU 自身电源作参考时，读数是相对电源的比例测量；测电池绝对电压需可靠基准或校准策略。

# 【六】调试与常见错误

| 现象 | 常见原因 | 优先检查 |
| --- | --- | --- |
| 读数总接近满量程/零 | 引脚复用或参考配置错误、输入超范围 | 寄存器配置、输入电压、VREF |
| 读数跳动很大 | 输入悬空、地噪声、参考不稳 | 加已知低阻电压源、检查去耦/接地 |
| 直流读数偏低 | 源阻抗高、采样时间短 | 延长采样时间、减小阻抗或加缓冲 |
| 波形频率不对 | 采样率不足、混叠 | 提高采样率并加抗混叠滤波 |
| 标称高位数却无改善 | 噪声/INL/参考限制 | 看 ENOB、噪声、基准与布局 |

调试时先把 ADC 输入接到已知的 GND、稳定基准或分压电源，验证零点和满量程附近的代码；再接入传感器。不要一开始就在未知的高阻、噪声信号上判断 ADC 是否“坏了”。
