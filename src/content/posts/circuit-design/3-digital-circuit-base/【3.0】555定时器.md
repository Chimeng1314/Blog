# 【一】555 定时器概览

555 是经典定时器 IC。其内部包含三等分电阻分压、两个比较器、RS 锁存器、放电晶体管和输出级；外接电阻、电容即可构成延时、单稳态、多谐振荡器和简单 PWM 电路。

![555 定时器内部功能框图](https://oss.silentdream.top/2026/10/02/01-12-28-e0cfbf9b-image-20261001215200603-441ef8.png)

常见型号：NE555/LM555 为双极型，输出驱动能力较强但静态电流较大；TLC555/LMC555/7555 等 CMOS 型通常静态电流更低、适合更高阻值的定时网络。不同型号的工作电压范围、输出电流和阈值误差不同，设计前应查数据手册。

# 【二】引脚与内部阈值

## 【1】八个引脚的作用

![NE555 引脚图](https://oss.silentdream.top/2026/10/02/01-12-28-b3480736-image-20261001215305350-090e68.png)

| 引脚 | 名称 | 作用 |
| --- | --- | --- |
| 1 | GND | 电源负端 |
| 2 | TRIG（触发） | 低于约 `1/3 VCC` 时置位，启动定时 |
| 3 | OUT（输出） | 推挽输出，驱动能力以具体型号为准 |
| 4 | RESET（复位） | 低有效，拉低会强制输出低、放电管导通 |
| 5 | CTRL（控制电压） | 改变内部阈值；不用时常通过约 10 nF 对地去耦 |
| 6 | THRESH（阈值） | 高于约 `2/3 VCC` 时复位，结束定时 |
| 7 | DISCH（放电） | 内部放电管的集电极，导通时拉向 GND |
| 8 | VCC | 电源正端 |

内部默认比较阈值约为 `1/3 VCC` 和 `2/3 VCC`；因此供电电压波动会影响绝对阈值和定时。精度受 R、C 容差和温漂主导，不能把 555 当作高精度时钟源。

## 【2】核心状态关系

```text
TRIG < 1/3 VCC       → 锁存器置位 → OUT 高，7 脚放电管截止
THRESH > 2/3 VCC     → 锁存器复位 → OUT 低，7 脚放电管导通
RESET 被拉低         → 强制复位  → OUT 低，7 脚放电管导通
```

> **构图说明**：TRIG 与 THRESH 不是普通数字输入；它们是模拟比较器输入。过冲、噪声和高阻 RC 节点都会影响切换时刻。

# 【三】无稳态电路（多谐振荡器）

无稳态电路没有稳定状态，会连续输出方波。电容在约 `1/3 VCC` 与 `2/3 VCC` 之间反复充、放电。

![555 无稳态/多谐振荡器连接示意](https://oss.silentdream.top/2026/10/02/01-12-28-e6322fc0-image-20261001215335890-4606b5.png)

```text
VCC ── R_A ──●── R_B ──●── C ── GND
             │         │
            7 脚      2、6 脚

充电：VCC → R_A → R_B → C
放电：C → R_B → 7 脚内部放电管 → GND
```

![555 无稳态电路原理图](https://oss.silentdream.top/2026/10/02/01-12-28-823aba0e-image-20261001215653066-eca8b1.png)

## 【1】充放电过程

- 电容电压低于 `1/3 VCC`：触发比较器置位，输出为高，7 脚截止；电容经 `R_A + R_B` 充电；
- 电容电压升至 `2/3 VCC`：阈值比较器复位，输出为低，7 脚导通；电容经 `R_B` 放电；
- 电容电压降至 `1/3 VCC`：再次置位，循环重复。

![电容充电时间关系](https://oss.silentdream.top/2026/10/02/01-12-28-5cf0cc96-image-20261001220118331-2e4fdf.png)

![电容放电时间关系](https://oss.silentdream.top/2026/10/02/01-12-28-4ea03915-image-20261001220134243-8bceb9.png)

## 【2】周期、频率和占空比

标准接法的高、低电平时间近似为：

$$
t_H\approx0.693\left(R_A+R_B\right)C
$$

$$
t_L\approx0.693R_BC
$$

$$
T\approx0.693\left(R_A+2R_B\right)C
$$

$$
f\approx\frac{1.44}{\left(R_A+2R_B\right)C}
$$

$$
D\approx\frac{R_A+R_B}{R_A+2R_B}
$$

![555 无稳态的周期关系](https://oss.silentdream.top/2026/10/02/01-12-28-e79dd1de-image-20261001220148769-962b53.png)

![555 无稳态的占空比关系](https://oss.silentdream.top/2026/10/02/01-12-28-b9683e1d-image-20261001220200235-7a82cd.png)

标准无稳态接法中 `R_A` 必须大于 0，故占空比通常大于 50%。若需要接近或小于 50%，可在 `R_B` 两端加入二极管分离充、放电路径，或改用 MCU PWM/专用振荡器。

# 【四】单稳态与双稳态

## 【1】单稳态：一次触发，一个定宽脉冲

单稳态平时保持稳定输出；TRIG 接收到一个有效低脉冲后，输出翻转一段时间，电容充到 `2/3 VCC` 后自动恢复。

```text
触发输入： ───────┐ ┌────────
                   └─┘
输出脉冲： ────────┌──────┐───
                   │  tW  │
                   └──────┘
```

脉冲宽度近似为：

$$
t_W\approx1.1RC
$$

适合上电延时、脉冲展宽、简单定时。重复触发、复位脚状态和触发脉宽是否满足数据手册要求会影响实际行为。

## 【2】双稳态：两个稳定状态

将 TRIG、RESET 等引脚用作置位/复位控制，可让 555 保持高、低两个稳定状态，功能类似简单锁存器。现代数字系统通常会用专用触发器或 MCU 实现，555 更适合教学或少量分立电路场景。

# 【五】仿真、设计与调试

## 【1】输出方波仿真

![555 多谐振荡器仿真波形](https://oss.silentdream.top/2026/10/02/01-12-28-86ccbd04-image-20261001220300800-71aaaf.png)

观察时应同时看 2/6 脚电容电压和 3 脚输出：电容电压应在约 `1/3 VCC` 与 `2/3 VCC` 之间呈指数形变化，输出为对应方波。

## 【2】设计示例：约 1 s、90% 占空比

设 `C = 10 µF`，希望 `T ≈ 1 s`、`D ≈ 90%`。标准无稳态公式给出：

```text
D ≈ (R_A + R_B) / (R_A + 2R_B) ≈ 0.9
可先取 R_A 约为 8R_B，再用 T ≈ 0.693(R_A + 2R_B)C 选标准阻值。
```

![555 方波产生练习图](https://oss.silentdream.top/2026/10/02/01-12-28-a8219cd6-image-20261001220548873-104e94.png)

实际误差可能达到数十个百分点：电解电容容差和漏电大、NE555 阈值有误差、R/C 温漂也会影响结果。若周期需要长期稳定，应使用晶振、RTC 或 MCU 定时器。

## 【3】常见问题

- VCC 与 GND 旁缺少去耦，导致输出切换时误触发；应在芯片附近放置 0.1 µF，电源入口再配合较大电容。
- RESET 悬空，造成偶发复位；不用时应可靠拉到 VCC。
- 用极高阻值电阻配 NE555，受输入漏电影响大；CMOS 555 更适合低功耗/高阻定时。
- 直接用 3 脚驱动电机或大继电器；应使用晶体管/MOSFET 驱动并加续流保护。
- 测量高阻定时节点时探头电容改变周期；优先用 ×10 探头并考虑其负载效应。
