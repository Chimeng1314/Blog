# 【一】施密特触发器与滞回比较器

施密特触发器（Schmitt Trigger）是一种带**滞回特性**的比较/数字输入电路。

普通比较器只有一个阈值；施密特触发器对输入上升和下降使用两个不同阈值，因此能把缓慢变化或带噪声的信号转换为稳定的数字高低电平。

![施密特触发器符号](https://oss.silentdream.top/2026/10/02/01-12-28-09c4edc5-image-20261001214507654-b741c0.png)

> **读图提示**：符号内的滞回标记说明该输入带有两个切换阈值。施密特触发器可以是反相型，也可以是同相型；输出翻转方向取决于具体器件和接法，不能只背一种波形。

## 【1】两个阈值与滞回宽度

- `V_T+`：输入**上升**时触发翻转的阈值（upper threshold）；
- `V_T−`：输入**下降**时触发翻转的阈值（lower threshold）；
- 滞回宽度为 `V_H = V_T+ − V_T−`。

```text
输入从低往高：达到 V_T+ 才翻转
输入从高往低：降到 V_T− 才翻转

电压
 V_T+ ─────────────── 上升触发线
          ↑  输入在此区间来回波动时，输出保持原状态
 V_T− ─────────────── 下降触发线
```

若输入始终在两个阈值之间，输出会保持上一状态；这正是“滞回”抑制噪声反复翻转的机制。

# 【二】工作原理与波形关系

## 【1】为什么单阈值会抖动

```text
单阈值比较器：

输入：    缓慢上升且叠加噪声，反复越过一个阈值
输出：    0 ──┐┌─┐┌───  → 多次误翻转
              └┘ └┘
```

当传感器信号、长导线输入或机械按键在阈值附近带噪声时，单一阈值会产生多次跳变。施密特触发器的两个阈值要求输入跨越更大的范围，能显著提高噪声容限。

## 【2】反相与同相的输出关系

以常见的**反相施密特触发器**为例：

```text
输入上升：Vin < V_T+ 时，Vout 为高；Vin ≥ V_T+ 后，Vout 翻为低
输入下降：Vin > V_T− 时，Vout 保持低；Vin ≤ V_T− 后，Vout 翻为高
```

同相型的输出方向相反，但仍遵守“上升跨过上阈值、下降跨过下阈值”的规则。数据手册常把阈值写成 `V_T+ / V_T−`、`V_IH / V_IL` 或保证范围；阈值会随供电电压、温度和工艺变化。

![施密特触发器滞回传输特性](https://oss.silentdream.top/2026/10/02/01-12-28-a83596dd-image-20261001214757919-c6b4c1.png)

> **读图提示**：沿上升箭头与下降箭头读取曲线，会看到同一个输入电压可能对应两种保持状态；这不是矛盾，而是电路保存了前一状态。

## 【3】温控报警例子

设高温报警上阈值为 70 ℃、解除阈值为 60 ℃：升温到 70 ℃时开启风扇/报警；降温到 60 ℃才关闭。若只设单一 70 ℃ 阈值，温度在 69～71 ℃ 附近波动时，输出会频繁启停。

# 【三】典型用途

## 【1】波形整形与阈值检测

```text
缓慢边沿/正弦波/含噪信号 ──→ [ 施密特触发器 ] ──→ 干净的数字方波
```

它适合把 RC 充放电波形、光电传感器输出、霍尔传感器边沿等送入数字逻辑。它不会消除所有模拟噪声，而是在跨越阈值时给出确定的数字判定；若噪声幅度超过滞回宽度，仍会发生误触发。

## 【2】RC 振荡器

电容电压在两个阈值之间反复充放电，输出因而产生方波：

```text
输出 ── R ──●── 施密特输入
            │
            C
            │
           GND
```

![施密特触发器 RC 振荡器](https://oss.silentdream.top/2026/10/02/01-12-28-23bb340a-image-20261001215014047-600e71.png)

> **构图说明**：输出为高时经 R 给 C 充电；跨过一个阈值后输出翻转，C 又经 R 朝相反方向变化。频率受 R、C、阈值比例和门电路延迟共同影响，精密定时应选晶振或专用时钟源。

## 【3】按键去抖

机械按键闭合与断开时，触点会在数毫秒内多次弹跳。RC 网络先把尖锐跳变变缓，施密特输入再以滞回给出一次干净翻转：

```text
VCC ── R ──●── 施密特输入 ── MCU GPIO
            │
          按键
            │
           GND
            │
            C
            │
           GND
```

![RC 加施密特触发器的按键去抖](https://oss.silentdream.top/2026/10/02/01-12-28-24da749f-image-20261001215044603-e4690b.png)

RC 值不能只凭感觉增大：过小去抖不足，过大会使按键响应迟缓；还要考虑输入漏电、阈值范围和 MCU 软件去抖策略。对于大多数 MCU 按键，硬件去抖和软件定时确认可以组合使用。

# 【四】器件、设计与调试要点

## 【1】与比较器的区别

| 项目 | 施密特触发器 | 通用比较器 |
| --- | --- | --- |
| 阈值 | 内置或固定滞回 | 默认单阈值，可外加正反馈形成滞回 |
| 输出 | 常为数字逻辑电平 | 可能为开漏/开集或推挽，需看型号 |
| 用途 | 数字整形、去抖、简单振荡 | 精确阈值检测、窗口比较、模拟控制 |
| 速度/精度 | 以逻辑应用为主 | 范围很广，需考虑输入共模与响应速度 |

不要把所有带滞回的器件都叫“触发器”。它在这里通常指带滞回的比较输入，并非寄存器/边沿触发 D 触发器。

## 【2】常见失效原因

- 输入幅度没有跨过器件在最坏条件下的 `V_T+ / V_T−`，导致从不翻转；
- 输入过冲超过电源轨或绝对最大额定值，损伤输入保护结构；
- CMOS 输入悬空，或 RC 节点漏电/污染严重，导致阈值时间不可预测；
- 长线输入未做 ESD、串联限流和适当滤波，噪声幅度大于滞回宽度；
- 忽略传播延迟，用该电路产生过高频率或精确占空比。

## 【3】测量方法

用示波器同时看输入和输出：缓慢扫过阈值时，记录上升翻转点和下降翻转点；两者之差就是实际滞回宽度。测高阻 RC 节点时应使用 ×10 探头，避免探头电容显著改变时间常数。
