# 【补充】后端接口处理跨域

## 【1】安装

```python
pip3.9 install django-cors-headers
```

## 【2】注册app

```python
INSTALLED_APPS = (
    ...
    'corsheaders',
    ...
)
```

## 【3】配置中间件

```python
MIDDLEWARE = [  
    ...
    'corsheaders.middleware.CorsMiddleware',
    ...
]
```

## 【4】配置文件

- 配置文件中加入：setting下面添加下面的配置

```python
CORS_ORIGIN_ALLOW_ALL = True
CORS_ALLOW_METHODS = (
    'DELETE',
    'GET',
    'OPTIONS',
    'PATCH',
    'POST',
    'PUT',
    'VIEW',
)

CORS_ALLOW_HEADERS = (
    'XMLHttpRequest',
    'X_FILENAME',
    'accept-encoding',
    'authorization',
    'content-type',
    'dnt',
    'origin',
    'user-agent',
    'x-csrftoken',
    'x-requested-with',
    'Pragma',
    'token'
)
```
