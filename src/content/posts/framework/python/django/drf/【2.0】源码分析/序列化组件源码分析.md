# 【一】序列化组件介绍

- Django REST framework（DRF）中的序列化和反序列化组件由`serializer`模块提供。
- 这些组件用于将数据模型转换为JSON或其他格式（序列化），以及将接收的数据反序列化为模型实例。

# 【二】 序列化（Serialization）

- 序列化是将数据模型转换为可传输或可存储格式的过程，通常是JSON格式。
- 在DRF中，序列化用于将数据库中的模型对象转换为JSON格式，以便通过API发送给客户端。

## 【1】序列化的使用流程

### **（1）导入Serializer类**

```python
from rest_framework import serializers
```

### **（2）定义Serializer类**

- 创建一个Serializer类，该类继承自 `serializers.Serializer`，并定义要序列化的字段：

```python
from rest_framework import serializers

class BookSerializer(serializers.Serializer):
    # 要序列化的字段
    id = serializers.IntegerField()
    name = serializers.CharField()
    price = serializers.IntegerField()
```

### **（3）创建Serializer实例并序列化数据**

- 通过序列化对象 .data 获取到序列化后的数据

```python
class BookView(APIView):
    def get(self, request):
        book_list = models.Book.objects.all()
        # 使用序列化类完成序列化
        # instance : 实例(对象)
        # data ： 数据
        # many=True : 如果是queryset对象，一般都是必须加
        # many=False : 如果是 .first() 一般不写，默认不写是 False
        book_ser = BookSerializer(instance=book_list, many=True)
        data = book_ser.data  # 将 book_ser 转成字典 -- 列表套字典
        print(f"data的数据是{data}", f"data的类型是{type(data)}")
        # data的数据是[OrderedDict([('id', 1), ('name', '西游记'), ('price', 999)])]
        # data的类型是<class 'rest_framework.utils.serializer_helpers.ReturnList'>

        return Response({"code": 1000, "msg": "查询成功", "data": data})
```

# 【三】反序列化（Deserialization）

- 反序列化是将接收到的数据（通常是JSON）转换为模型对象的过程。
- 这是在客户端发送数据到API时发生的过程，DRF将数据转换为模型对象以进行保存或进一步处理。
