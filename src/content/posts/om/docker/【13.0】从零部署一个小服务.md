这个练习故意不依赖数据库和编程语言。完成后，你应能解释：网页文件放在哪里、容器监听哪个端口、宿主机从哪个端口访问，以及删除容器后文件是否还在。

# 【一】准备目录和网页

```bash
mkdir -p docker-web-lab/site
cd docker-web-lab
cat > site/index.html <<'EOF'
<!doctype html>
<html lang="zh-CN">
<meta charset="utf-8">
<title>Docker 练习</title>
<h1>你好，Docker！</h1>
<p>这是由 Nginx 容器提供的本地页面。</p>
EOF
```

这里的 `site/` 是宿主机目录。`index.html` 可以用任何编辑器修改，绑定挂载会让容器直接看到变更。

# 【二】创建 `compose.yaml`

```yaml
services:
  web:
    image: nginx:alpine
    ports:
      - "127.0.0.1:8080:80"
    volumes:
      - ./site:/usr/share/nginx/html:ro
    restart: unless-stopped
```

把以上内容保存到 `docker-web-lab/compose.yaml`。`ro` 是只读：Nginx 能读取网页，不能从容器修改宿主机的网页目录。练习里用 `nginx:alpine` 便于上手；正式部署可固定明确版本或摘要。

# 【三】启动、观察和修改

```bash
docker compose config
docker compose up -d
docker compose ps
curl http://127.0.0.1:8080
docker compose logs --tail 30 web
```

浏览器打开 `http://localhost:8080`。接着修改 `site/index.html` 的文字并刷新页面，通常无需重建镜像。若 8080 已被占用，把宿主机端口改成 8081，并访问 `http://localhost:8081`。

# 【四】停止和复盘

```bash
docker compose down
ls site/index.html
```

容器和项目网络被删除，但网页文件仍在宿主机目录。练习结束后若不再需要，可以手动删除自己创建的 `docker-web-lab/` 目录；不要在别的项目目录直接照抄删除命令。
