# C 语言开发环境的安装与配置

编写并运行一个 C 程序，至少需要以下两类工具：

1. **代码编辑器或集成开发环境（IDE）**：用于编写和管理源代码。
2. **C 工具链**：通常包含编译器、链接器、调试器和构建工具。

> **注意：** Visual Studio Code 只是代码编辑器。安装 C/C++ 扩展后，还需要单独安装 GCC、Clang 或 MSVC 等编译器，才能编译和运行 C 程序。

# 【一】开发工具的组成

| 工具 | 作用 | 常见选择 |
| --- | --- | --- |
| 编辑器 / IDE | 编写代码、管理文件、提供代码提示 | Visual Studio Code、Visual Studio、CLion、Vim |
| 编译器 | 将 C 源代码翻译为目标代码 | GCC、Clang、MSVC |
| 链接器 | 将目标文件和库组合成可执行程序 | GNU `ld`、LLVM `lld`、MSVC LINK |
| 调试器 | 单步执行、查看变量和调用栈 | GDB、LLDB、Visual Studio Debugger |
| 构建工具 | 自动执行多文件编译和链接 | Make、CMake、Ninja |

C 源文件通常使用 `.c` 扩展名，头文件通常使用 `.h` 扩展名。例如：

```text
hello.c       C 源文件
student.h     头文件
```

# 【二】编辑器的选择

## 【1】Visual Studio Code

Visual Studio Code（简称 VS Code）体积较小、跨平台且扩展丰富，适合初学者使用。

- 下载地址：[Visual Studio Code 官网](https://code.visualstudio.com/)
- C/C++ 扩展：[Microsoft C/C++](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools)

安装 VS Code 后，在扩展面板中搜索并安装 Microsoft 发布的 **C/C++** 扩展。该扩展提供代码补全、语法检查和调试支持，但编译器仍需单独安装。

> 初学阶段建议先在终端中手动执行编译命令。这样可以清楚理解“源文件 → 编译 → 可执行文件 → 运行”的过程。

## 【2】其他选择

- **Visual Studio**：适合 Windows，内置 MSVC 工具链和图形化调试器。
- **CLion**：跨平台商业 IDE，学生和符合条件的开源开发者可申请免费许可。
- **Vim / Neovim / Emacs**：高度可定制，适合熟悉命令行的用户。
- **Sublime Text**：轻量、启动快，但编译和调试通常需要自行配置。

> Atom 已于 2022 年停止官方维护，不建议再作为新的 C 语言学习环境。

# 【三】Windows 环境安装（推荐）

Windows 上可以选择 GCC、MSVC 或 WSL 等开发方案。本文采用以下组合搭建 C 语言开发环境：

```text
VS Code + MinGW-w64 工具链（GCC + GDB）
```

## 【3】验证安装

完全关闭并重新打开 VS Code，然后新建一个 PowerShell 终端，依次执行：

```powershell
gcc --version
gdb --version
Get-Command gcc
gcc -dumpmachine
```

如果安装正确：

- `gcc --version` 会显示 GCC 版本信息；
- `gdb --version` 会显示 GDB 版本信息；
- `Get-Command gcc` 会显示 `gcc.exe` 的实际路径；
- 对于 64 位 MinGW-w64，`gcc -dumpmachine` 的结果通常包含 `x86_64-w64-mingw32`。

# 【四】编写并运行第一个 C 程序

## 【1】创建项目目录

建议为每个项目单独建立文件夹。例如：

```text
C:\Code\c-study\hello
```

使用 VS Code 打开该文件夹，然后新建 `hello.c`：

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, C!\n");
    return 0;
}
```

## 【2】编译程序

在 VS Code 中选择“终端 → 新建终端”，执行：

```powershell
gcc -std=c17 -Wall -Wextra -Wpedantic -g hello.c -o hello.exe
```

各参数含义：

| 参数 | 作用 |
| --- | --- |
| `-std=c17` | 按 C17 标准编译 |
| `-Wall -Wextra -Wpedantic` | 开启常用警告，帮助发现潜在问题 |
| `-g` | 写入调试信息，供 GDB 使用 |
| `hello.c` | 输入的 C 源文件 |
| `-o hello.exe` | 指定生成的可执行文件名 |

> 编译成功时，GCC 通常不会输出任何信息。没有消息往往表示没有发现错误。

## 【3】运行程序

在 PowerShell 中执行：

```powershell
.\hello.exe
```

预期输出：

```text
Hello, C!
```

PowerShell 默认不会直接从当前目录查找程序，因此需要使用 `.` 表示当前目录，即写成 `.\hello.exe`。

# 【五】Windows 上的其他方案

## 【1】Visual Studio + MSVC

如果希望使用完整 IDE，可以安装 [Visual Studio Community](https://visualstudio.microsoft.com/vs/community/)。在安装器中选择：

```text
使用 C++ 的桌面开发（Desktop development with C++）
```

虽然工作负载名称包含“C++”，其中的 MSVC 编译器同样可以编译 C 程序。在 “Developer PowerShell for VS” 中可以这样编译：

```powershell
cl /W4 /Zi hello.c
.\hello.exe
```

MSVC 与 GCC 的命令行参数不同，不能直接照搬 GCC 的参数。

## 【2】WSL（适合学习 Linux 开发）

WSL 可以在 Windows 中提供 Linux 环境。管理员 PowerShell 中执行：

```powershell
wsl --install
```

进入 Ubuntu 后安装工具链：

```bash
sudo apt update
sudo apt install build-essential gdb
```

WSL 中生成的是 Linux 可执行文件，应在 WSL 内使用 `./hello` 运行，而不是在 Windows 中运行。

# 【七】macOS 环境安装

macOS 推荐安装 Apple Command Line Tools：

```bash

cc -std=c17 -Wall -Wextra -Wpedantic -g hello.c -o hello
./hello
```

# 【八】常见问题排查

## 【1】提示“无法识别 gcc”或“gcc 不是内部或外部命令”

可能原因：

- 工具链尚未安装；
- MinGW-w64 安装目录下的 `bin` 文件夹没有加入 `Path`；
- 修改 `Path` 后没有重启终端或 VS Code；
- `Path` 中存在其他旧版 GCC，导致工具冲突。

在 PowerShell 中检查：

```powershell
Get-Command gcc -All
```

## 【2】安装了 VS Code 扩展却不能编译

C/C++ 扩展只提供代码编辑、代码提示和调试集成，不包含编译器。按照本文的技术路线，还需要单独安装 MinGW-w64 工具链。

## 【3】出现 `No such file or directory`

先确认终端所在目录和文件名：

```powershell
Get-Location
Get-ChildItem
```

然后确认当前目录中确实存在 `hello.c`。文件扩展名也可能被 Windows 隐藏，应避免将文件误命名为 `hello.c.txt`。

## 【4】双击程序后窗口一闪而过

不要通过双击运行控制台程序。应在 PowerShell、Windows Terminal 或 VS Code 终端中执行：

```powershell
.\hello.exe
```

## 【5】中文输出乱码

初学阶段可先使用英文路径、英文文件名和英文输出，减少编码问题。需要输出中文时，应确保源文件、终端和程序使用兼容的字符编码；在现代 Windows Terminal 中通常建议统一使用 UTF-8。

## 【6】`gcc` 和 `g++` 有什么区别

- `gcc`：用于编译 C 程序；
- `g++`：用于编译 C++ 程序，并自动链接 C++ 标准库。

学习 C 语言时，源文件应使用 `.c` 扩展名，并使用 `gcc` 编译。

# 【九】推荐的学习配置

对于 Windows 初学者，建议统一使用以下组合：

| 项目 | 推荐选择 |
| --- | --- |
| 编辑器 | Visual Studio Code |
| 编辑扩展 | Microsoft C/C++ |
| 工具链 | MinGW-w64 GCC |
| 调试器 | GDB |
| 语言标准 | C17（兼容性较好） |
| 编译警告 | `-Wall -Wextra -Wpedantic` |

C23 已正式发布，但不同编译器对其特性的支持程度不一致。基础学习阶段使用 C17 更稳定；学习 C23 新特性时，再根据编译器版本选择 `-std=c23` 或旧版 GCC 使用的 `-std=c2x`。
