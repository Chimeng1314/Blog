# 【一】表达式
*   **定义**：所谓表达式是指由运算符、运算量和标点符号组成的有效序列，是用来说明一个计算过程。
*   **表达式语句**：表达式可以独立形成语句，该语句称为表达式语句。
*   **一般形式**：
    `<表达式> ;` （注意末尾必须有分号）

# 【三】整数除法和实数除法

C语言的除法运算符分为整数除法和实数除法。

## 【1】整数除法
*   **求整 `/`**：得到两个整数相除的**整数部分**。
*   **求余 `%`**：得到两个整数相除的**余数部分**。
*   **举例**：
    *   `1/2` 的结果为 `0` （小数部分被直接丢弃）
    *   `1%2` 的结果为 `1` （1除以2，商0余1）

## 【2】实数除法
*   **除法 `/`**：得到两个实数相除的结果为一个**实数**。
*   **举例**：
    *   `1.0/2` 的结果为 `0.5`

## 【1】除法运算符

* **题目**：计算 `1/2`、`1.0/2`、`1%2` 的结果分别是多少？

*   **源代码**：
    ```c
    #include <stdio.h>
    
    int main(int argc, char const *argv[])
    {
        printf("1/2 =%d\n",1/2);
        printf("1.0/2=%f\n",1.0/2);
        printf("1%%2 =%d\n",1%2);
        return 0;
    }
    ```
    
*   **运行结果**：
    ```text
    1/2=0
    1%2=1
    1.0/2=0.500000
    ```

## 【2】自增自减运算符

### （1）自增运算符
*   `i++`：表示 `i` 的值**先参与运算**，最后再自增1（后缀）。
*   `++i`：表示 `i` 的值**先自增1**，之后再参与运算（前缀）。

### （2）自减运算符
*   `i--`：表示 `i` 的值**先参与运算**，最后再自减1（后缀）。
*   `--i`：表示 `i` 的值**先自减1**，之后再参与运算（前缀）。

---

**假设每一行代码都从头执行，即初始值始终是 `x=5, y=9`**。如果连续执行而不重置变量，结果会不同。

我们按照图片给出的初始值 `x=5, y=9`，逐行拆解：

1.  `z = ++x;` 
    *   前缀：`x`先加1变成6，然后把6赋给`z`。
    *   结果：`z=6`，`x=6`
2.  `z = x++;`
    *   后缀：先把`x`当前值5赋给`z`，然后`x`再加1变成6。
    *   结果：`z=5`，`x=6`
3.  `z = --x;`
    *   前缀：`x`先减1变成4，然后把4赋给`z`。
    *   结果：`z=4`，`x=4`
4.  `z = x--;`
    *   后缀：先把`x`当前值5赋给`z`，然后`x`再减1变成4。
    *   结果：`z=5`，`x=4`
5.  `z = ++x+y++;`
    *   前缀+后缀混合：`++x`使`x`变成6（取6参与运算），`y++`取`y`当前值9参与运算（然后`y`变成10）。`z = 6 + 9 = 15`。
    *   结果：`z=15`，`x=6`，`y=10`
6.  `z = --x+y++;`
    *   `--x`使`x`变成4（取4参与运算），`y++`取`y`当前值9参与运算（然后`y`变成10）。`z = 4 + 9 = 13`。
    *   结果：`z=13`，`x=4`，`y=10`
7.  `z = ++x+y--;`
    *   `++x`使`x`变成6（取6参与运算），`y--`取`y`当前值9参与运算（然后`y`变成8）。`z = 6 + 9 = 15`。
    *   结果：`z=15`，`x=6`，`y=8`

## 【3】算术运算符 

* **源代码**（基于输出结果还原，利用重置变量来独立验证每一行的逻辑）：
  ```c
  #include <stdio.h>
  
  int main() {
      int x, y, z;
  
      // 第一行
      x = 5; y = 9; z = ++x;      // 前缀：x先加1变6，z=6
      printf("z=%d, x=%d\n", z, x);
      
      // 第二行
      x = 5; y = 9; z = x++;      // 后缀：z=5，x再加1变6
      printf("z=%d, x=%d\n", z, x);
      
      // 第三行
      x = 5; y = 9; z = --x;      // 前缀：x先减1变4，z=4
      printf("z=%d, x=%d\n", z, x);
      
      // 第四行
      x = 5; y = 9; z = x--;      // 后缀：z=5，x再减1变4
      printf("z=%d, x=%d\n", z, x);
      
      // 第五行
      x = 5; y = 9; z = ++x + y++; // ++x为6，y++取9，z=15；运算后x=6, y=10
      printf("z=%d, x=%d, y=%d\n", z, x, y);
      
      // 第六行
      x = 5; y = 9; z = --x + y++; // --x为4，y++取9，z=13；运算后x=4, y=10
      printf("z=%d, x=%d, y=%d\n", z, x, y);
      
      // 第七行
      x = 5; y = 9; z = ++x + y--; // ++x为6，y--取9，z=15；运算后x=6, y=8
      printf("z=%d, x=%d, y=%d\n", z, x, y);
  
      return 0;
  }
  ```
