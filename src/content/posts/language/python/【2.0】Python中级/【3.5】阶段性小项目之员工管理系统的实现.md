# 【一】需求分析
+ 我们在企业或班级中经常会看到需要统计员工信息的相关需求
+ 而我们想要实现的就是一个简单的员工管理系统
+ 大致功能包括添加用户、查看用户、删除用户、修改用户、退出系统

# 【三】功能分析
## 【1】 功能列表
+ 让用户直接看到打印序号的功能
    - 添加用户
    - 查看用户
    - 删除用户
    - 退出系统

## 【2】 需要实现的功能
### （1）添加用户
+ 判断用户是否存在 
    - 用户存在则重新输入
    - 用户不存在则添加
+ 用户可以添加自己的信息 信息包括：用户名、年龄、薪资、爱好 并将数据存储到信息列表里

### （2）查看用户信息功能（可选择）
+ 用户可以指定查看指定用户的信息
+ 用户可以查看所有用户的信息

### （3）删除用户功能
+ 用户可以按照指定编号删除用户

### （4）修改指定用户信息
### （5）退出系统
# 【四】实现功能分析
## 【1】添加用户功能
+ 接收到正确指令，进入录入用户信息系统
+ 先校验用户信息
    - 如果用户信息存在。
        * 则退出当前功能
    - 如果用户信息不存在
        * 录入用户信息
        * 信息包括
            + 姓名
            + 年龄
            + 薪资
            + 爱好
            + 总信息格式为

```plain
[{'username': 'dream', 'age': 18, 'salary': 10000, 'hobby': 'music'}]
```

+ 录入信息结束，询问是否仅需录入或者退出当前功能

## 【2】查看用户信息功能
+ 先接受指令，进入查看用户信息功能
+ 录入指令

```plain
1.查看指定用户信息
2.查看全部用户信息
```

+ 进入指令查看

### （1）查看指定用户信息
+ 接受指令，进入查看指定用户信息功能
+ 输入需要查看的用户姓名
+ 从数据库检索用户信息 
    - 如果存在 
        * 则打印输出用户信息
    - 如果不存在 
        * 则提示这个用户不存在

### （2）查看全部用户信息
+ 接受指令。进入查看全部用户信息功能
+ 输入查看用户的姓名
+ 从数据库检索信息并打印输出

## 【3】删除信息功能
+ 先接受指令，进入删除用户信息功能
+ 录入指令

```plain
1.删除指定用户信息
2.删除全部用户信息
```

+ 进入指令查看

### （1）删除指定用户信息功能
+ 接受执行，进入删除指定用户信息功能
+ 先打印输出数据库信息
+ 输入需要删除的指定用户名
+ 检索用户名是否存在 
    - 如果用户名存在 
        * 删除指定用户信息
    - 如果用户不存在 
        * 退出功能

### （2）删除全部信息功能
+ 接受指令，进入删除全部用户信息功能
+ 先打印输出数据库信息
+ 数据库信息清空

## 【4】修改指定用户信息
## 【5】退出系统功能
+ 先接受指令，进入退出用户系统
+ 录入指令

```plain
1.退出到功能界面
2.完全退出系统
```

+ 进入指令

### （1）退出到用户功能选择界面
+ 接受指令，进入退出用户系统界面
+ 执行返回功能界面操作

### （2）退出全部系统
+ 接受指令，退出全部系统
