# 【二】架构设计
## 【1】用户视图层(前端)
+ 用于与用户进行交互，接收用户输入的数据
+ 将用户数据提交给逻辑接口层进行业务逻辑的处理
+ 展示业务逻辑处理后的结果

## 【2】逻辑接口层(后端)
+ 相当于用户视图层和数据处理层的桥梁
+ 专门负责接收用户视图层传过来的数据，并进行核心业务的校验，在处理数据过程中可能会访问数据库，读取相应的数据，并对数据进行修改
+ 所有业务处理完成后，会返回相应的结果给用户视图层，用户视图层再对结果进行展示

## 【3】数据处理层(数据库)
+ 接收到接口层传过来的数据，并对数据进行简单的处理
+ 主要负责数据的存储和数据的增删查改
