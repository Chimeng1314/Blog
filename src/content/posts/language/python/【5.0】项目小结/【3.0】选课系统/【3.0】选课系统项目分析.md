# 【一】项目名称
+ 选课系统

# 【二】角色信息
+ 学校、学员、课程、讲师

# 【三】详细需求
## 【1】创建学校
+ 创建北京、上海 2 所学校

## 【2】开设课程
+ 创建linux , python , go 3个课程
+ linux\py 在北京开， go 在上海开

## 【3】课程信息
+ 课程包含课程名称、课程周期、课程价格

## 【4】创建课程
+ 通过学校创建课程

## 【5】创建班级
+ 通过学校创建班级
+ 班级关联课程、讲师

## 【6】创建学员
+ 创建学员时
+ 选择学校，关联班级

## 【7】创建讲师
+ 创建讲师角色时要关联学校

## 【8】角色接口
+ 提供三个角色接口 
    - 学员视图 
        * 登录
        * 注册
        * 选择学校
        * 选择课程
        * 查看成绩
    - 讲师视图 
        * 登录
        * 选择学校
        * 选择课程
        * 查看课程下学员列表
        * 修改所管理的学员的成绩
    - 管理视图 
        * 登录
        * 注册
        * 创建讲师
        * 创建班级
        * 创建课程
        * 创建学校

# 【四】数据库
+ 上面的操作产生的数据都通过pickle序列化保存到文件里
