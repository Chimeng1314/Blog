# 【一】介绍
+ importlib 模块是 Python 中用于动态加载和导入模块的内置模块。
+ 它提供了一组函数和类，使得我们可以在运行时根据需要加载模块，并且可以对已导入的模块进行操作和管理。

# 【二】动态加载模块
+ importlib 模块提供了 import_module 函数
+ 通过该函数可以在运行时动态加载一个模块。

```python
import importlib

module_name = 'math'  # 要加载的模块名
math_module = importlib.import_module(module_name)
```

# 【三】导入指定模块成员
+ importlib 模块还提供了 import_module 函数的变体 import_module
+ 它可以直接返回指定模块的成员。

```python
import importlib

module_name = 'math'  # 要加载的模块名
math_module = importlib.import_module(module_name)
sqrt_func = getattr(math_module, 'sqrt')
```

# 【三】重新加载模块
+ 在开发过程中，我们有时需要重新加载一个已经导入的模块，以便应用最新的修改。
+ importlib 模块提供了 reload 函数来实现这个功能。：

```python
import importlib

module_name = 'my_module'  # 要重新加载的模块名
my_module = importlib.import_module(module_name)
my_module = importlib.reload(my_module)
```

# 【四】获取已导入的模块列表
+ 通过 sys.modules 可以获取当前已导入的所有模块的字典
+ 其中键为模块名称，值为模块对象。

```python
import sys

for module_name, module in sys.modules.items():
    print(module_name, module)
```

### （3）调用部分
+ 在外部定义一个配置文件
+ settings.py

```python
MODEL_LIST = [
    'send_message_package.Email.email',
    'send_message_package.QQ.QQ',
    'send_message_package.WeChat.WeChat',
]
```

+ 在外部的真正功能文件

```python
import settings
import importlib


def send_all(content):
    # 拿到每一个包的路径
    for path_str in settings.MODEL_LIST:
        model_path, class_name = path_str.rsplit('.', maxsplit=1)
        # model_path : model.email
        # class_name : email
        # （1）利用字符串导入模块
        # models : 模块对象
        models = importlib.import_module(model_path)
        # （2）利用反射拿到类名
        cls = getattr(models, class_name)
        # （3）生成类的对象
        obj = cls()
        # （4）利用鸭子类型直接调用send发送消息
        obj.send(content)


if __name__ == '__main__':
    send_all('1')
```

```plain
email 发送的消息 :>>>这是测试消息
QQ 发送的消息 :>>>这是测试消息
WeChat 发送的消息 :>>>这是测试消息
```

## 【4】小结
+ 遵从Python中的鸭子类型 
    - 可以在功能文件中自定义功能文件添加或者注释
+ 在 settings.py 文件中相关的路径注释掉或添加上去即可
